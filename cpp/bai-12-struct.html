C++ có giải pháp: struct — chiếc "hộp đa ngăn" gom nhiều giá trị khác kiểu thành một kiểu dữ liệu mới. Giống thẻ nhân vật trong game nhập vai: tên, máu, sát thương nằm chung một thẻ. Định nghĩa struct

struct cho phép bạn tự "đúc" một kiểu dữ liệu mới. Mỗi giá trị nằm bên trong gọi là một thuộc tính (member). Định nghĩa khuôn một lần, rồi khai báo biến thoải mái:

sinhvien.cpp 
#include <iostream>
#include <string>
using namespace std;

struct SinhVien {
    string ten;
    double diem;
};

int main() {
    SinhVien sv;              // biến kiểu SinhVien
    sv.ten = "An";            // truy cập thuộc tính bằng dấu chấm
    sv.diem = 8.5;
    cout << sv.ten << " - " << sv.diem << " diem" << endl;

    SinhVien sv2 = {"Binh", 7.0};   // khởi tạo nhanh cả hộp một lượt
    cout << sv2.ten << ": " << sv2.diem << endl;
    return 0;
}
▸ KẾT QUẢ 
An - 8.5 diem
Binh: 7

Trước khi đi tiếp, hãy giải phẫu "khuôn" struct — nhìn kỹ vì mọi thứ xoay quanh nó:

Quên dấu ; ngay sau } đóng struct là lỗi kinh điển nhất khi mới học struct. Compiler sẽ báo kiểu error: expected ';' after struct definition — và vị trí báo lỗi thường "lệch" xuống dòng dưới. Gặp lỗi này, hãy nhìn ngay lên dấu } đóng struct gần nhất!

Mảng struct & hàm

Một sinh viên thì dễ — cả lớp thì cần mảng struct. Mỗi phần tử là một "hồ sơ" đầy đủ, truy cập bằng ds[i].ten và duyệt bằng vòng for y như mảng số:

danhsach.cpp 
#include <iostream>
#include <string>
using namespace std;

struct SinhVien {
    string ten;
    double diem;
};

int main() {
    SinhVien ds[3];
    ds[0].ten = "An";    ds[0].diem = 8.5;
    ds[1].ten = "Binh";  ds[1].diem = 7.0;
    ds[2].ten = "Chi";   ds[2].diem = 9.5;

    for (int i = 0; i < 3; i++)
        cout << i + 1 << ". " << ds[i].ten << " - " << ds[i].diem << endl;
    return 0;
}
▸ KẾT QUẢ 
1. An - 8.5
2. Binh - 7
3. Chi - 9.5

Struct cũng có thể truyền vào hàm như biến thường. Điểm cần nhớ: có dấu & hay không sẽ quyết định hàm nhận "hồ sơ thật" hay "bản photocopy":

ham.cpp 
#include <iostream>
#include <string>
using namespace std;

struct SinhVien {
    string ten;
    double diem;
};

void inThongTin(SinhVien sv) {          // nhận bản sao
    cout << sv.ten << " duoc " << sv.diem << " diem" << endl;
}

void congDiem(SinhVien &sv) {           // nhận tham chiếu → sửa được gốc
    sv.diem += 1;
}

int main() {
    SinhVien sv = {"An", 8.5};
    inThongTin(sv);
    congDiem(sv);                       // 8.5 + 1 = 9.5
    inThongTin(sv);
    return 0;
}
▸ KẾT QUẢ 
An duoc 8.5 diem
An duoc 9.5 diem
// GHI NHỚ

Hàm void inThongTin(SinhVien sv) không có & sẽ sao chép toàn bộ struct — sửa trong hàm cũng không ảnh hưởng biến gọi. Thêm & thành SinhVien& sv để dùng chung hộp dữ liệu gốc, giống đưa chìa khóa thật thay vì phát cho người ta bản photocopy.

TỔNG KẾT BÀI 12

  • struct gom nhiều giá trị khác kiểu thành một kiểu dữ liệu mới; mỗi giá trị là một thuộc tính.
  • Định nghĩa: struct SinhVien { string ten; double diem; }; — nhớ dấu ; sau }.
  • Khai báo biến SinhVien sv; rồi truy cập thuộc tính bằng dấu chấm: sv.ten, sv.diem.
  • Có thể khởi tạo nhanh: SinhVien sv = {"An", 8.5}; — theo đúng thứ tự thuộc tính.
  • Mảng struct: SinhVien ds[3]; — truy cập ds[i].ten và duyệt bằng vòng for như mảng thường.
  • Hàm nhận SinhVien sv → bản sao; nhận SinhVien& sv → tham chiếu, sửa được gốc.
