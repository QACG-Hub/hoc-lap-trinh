Xử lý file với fstream

[ NHIỆM VỤ #19 ] Chương 6 — STL & nâng cao Mức độ: Cao thủ

Mọi chương trình tới lúc nào đó đều cần nhớ lâu. cout in xong là hết, tắt chương trình là biến số bay hơi. File là bộ nhớ vĩnh viễn của bạn: ghi điểm vào file để mở máy vẫn còn, đọc dữ liệu từ file thay vì gõ tay từng dòng. Thư viện <fstream> cho ta hai "con robot" đúng việc: ofstream chuyên ghi, ifstream chuyên đọc. 🗂️

ofstream — ghi file

Muốn ghi ra file, ta mở "ống nước" ofstream tới tên file, đẩy dữ liệu vào bằng << — y hệt cout — rồi đóng file:

ghi-file.cpp 
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream f("data.txt");     // mở (tạo) file data.txt để ghi
    f << "Xin chao file!" << endl;
    f << 2026 << endl;
    f.close();                  // đóng file — đừng quên!

    cout << "Da ghi xong data.txt" << endl;
    return 0;
}

Da ghi xong data.txt

Sau khi chạy, thư mục chương trình xuất hiện file data.txt với 2 dòng: Xin chao file! và 2026. Chương trình không tự in gì về file đó — nên bài này ta thêm dòng cout báo "xong" cho vui mắt (và để thấy chương trình thực sự chạy!). Giải phẫu dòng mở file:

Hai cái bẫy của ofstream: (1) quên f.close(); — chương trình vẫn chạy nhưng dữ liệu có thể chưa được đẩy hết xuống file, hãy tạo thói quen đóng file ngay khi ghi xong. (2) mở file đã tồn tại sẽ xoá sạch nội dung cũ và ghi lại từ đầu — muốn nối thêm vào cuối thì mở bằng ofstream f("data.txt", ios::app);.

ifstream — đọc file

Đọc file thì đổi "robot": dùng ifstream (input file). Sau khi mở, ta đọc từng dòng bằng getline(f, dong) — đúng hàm getline bạn học ở bài 17, chỉ đổi cin thành luồng file:

doc-file.cpp 
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream f("data.txt");     // mở file data.txt để đọc
    if (!f) {                   // không mở được? (file không tồn tại...)
        cout << "Khong mo duoc file!" << endl;
        return 1;
    }
    string dong;
    getline(f, dong);
    cout << "Dong 1: " << dong << endl;
    getline(f, dong);
    cout << "Dong 2: " << dong << endl;
    f.close();
    return 0;
}

Kết quả trên đọc đúng file do chương trình ở mục 1 tạo ra. Muốn đọc tới hết file mà không biết trước bao nhiêu dòng? Cho getline làm điều kiện của while:

doc-het-file.cpp 
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream f("data.txt");
    if (!f) {
        cout << "Khong mo duoc file!" << endl;
        return 1;
    }
    string dong;
    while (getline(f, dong)) {   // đọc tới khi hết file
        cout << dong << endl;
    }
    return 0;
}

// GHI NHỚ

while (getline(f, dong)) chạy cho tới khi getline thất bại (hết file) — mỗi vòng lặp dong là một dòng mới. Cả ofstream lẫn ifstream đều nằm trong <fstream>, và đường dẫn "data.txt" là tương đối — file được tạo/tìm ngay cạnh chương trình đang chạy.

// CẢNH BÁO

File không tồn tại không làm compiler báo lỗi — chương trình biên dịch ngon lành, chạy tới dòng getline rồi trả về chuỗi rỗng khiến kết quả "trống trơn" khó hiểu. Vì vậy hãy luôn kiểm tra if (!f) { ... } ngay sau khi mở file. Viết if (f) để hỏi ngược lại "mở thành công chứ?".

TỔNG KẾT BÀI 19

  • Làm việc với file cần #include <fstream> — trong đó có cả ofstream (ghi) và ifstream (đọc).
  • ofstream f("data.txt"); mở/tạo file để ghi; đẩy dữ liệu bằng f << ...; giống cout.
  • ifstream f("data.txt"); mở file để đọc; đọc từng dòng bằng getline(f, dong).
  • Luôn f.close(); khi xong, và luôn kiểm tra if (!f) { ... } ngay sau khi mở file để bắt lỗi "file không tồn tại".
  • Đọc hết file không cần biết số dòng: while (getline(f, dong)) { ... }.
  • Mở ofstream tới file đã có sẽ ghi đè nội dung cũ; dùng ios::app nếu muốn nối thêm.
