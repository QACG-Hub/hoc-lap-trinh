Con trỏ (pointer) cơ bản

[ NHIỆM VỤ #10 ] Chương 4 — Con trỏ & bộ nhớ Mức độ: Cao thủ

Đây là bài "ngầu" nhất chương này: con trỏ — thứ khiến C++ vừa mạnh mẽ vừa đáng sợ. Hãy tưởng tượng mỗi biến là một căn nhà, còn con trỏ chỉ là mẩu giấy ghi địa chỉ căn nhà đó. Nắm được mẩu giấy, bạn có thể tìm tới tận nơi và sửa mọi thứ bên trong. ⚡

Địa chỉ & con trỏ

Mọi biến trong bộ nhớ đều có một địa chỉ — na ná số nhà. Toán tử & đặt trước biến sẽ lấy ra địa chỉ đó; còn * khi khai báo sẽ tạo một con trỏ để giữ địa chỉ ấy. Dùng *p thêm lần nữa để "đi tới căn nhà" và lấy giá trị bên trong:

con-tro.cpp 
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int *p = &a;          // p trỏ tới a
    cout << a << endl;    // giá trị của a
    cout << *p << endl;   // giải tham chiếu: cũng là 5
    *p = 10;              // đổi giá trị qua con trỏ
    cout << a << endl;    // a đổi theo
    return 0;
}

Muốn "nhìn thấy" địa chỉ, chỉ cần in con trỏ hoặc &a ra — chúng sẽ in địa chỉ dạng số hệ 16:

dia-chi.cpp 
#include <iostream>
using namespace std;

int main() {
    int a = 5;
    int *p = &a;
    cout << "Dia chi cua a: " << &a << endl;
    cout << "p cung tro toi: " << p << endl;
    return 0;
}

Con trỏ & mảng + truyền vào hàm

Đây là bí mật động trời: tên mảng chính là con trỏ! Khi dùng một mình, arr tương đương &arr[0] — địa chỉ của phần tử đầu tiên. Vì thế bạn có thể dùng cú pháp con trỏ để duyệt mảng:

tro-vao-mang.cpp 
#include <iostream>
using namespace std;

int main() {
    int arr[3] = {10, 20, 30};
    int *p = arr;              // tên mảng = địa chỉ phần tử đầu
    cout << p[0] << endl;      // 10
    cout << *(p + 1) << endl;  // 20
    return 0;
}
▸ KẾT QUẢ 
10
20

*(p + 1) nghĩa là "đi thêm 1 ô nhớ rồi lấy giá trị" — tương đương p[1]. Giờ đến ứng dụng thực chiến nhất của con trỏ: truyền vào hàm để sửa giá trị gốc. Bình thường hàm nhận bản sao, sửa xong bản sao thì biến gốc "không biết gì"; nhưng nhận địa chỉ thì hàm chạm được tận biến gốc:

truyen-con-tro.cpp 
#include <iostream>
using namespace std;

void gapDoi(int *x) {      // hàm nhận ĐỊA CHỈ
    *x = *x * 2;           // sửa giá trị tại địa chỉ đó
}

int main() {
    int a = 5;
    gapDoi(&a);            // truyền địa chỉ của a
    cout << a << endl;      // a đã bị "chỉnh" từ trong hàm
    return 0;
}
▸ KẾT QUẢ 
10
// CẢNH BÁO

Con trỏ chưa trỏ tới đâu là một quả bom: int *p; *p = 5; sẽ ghi giá trị vào một vùng nhớ ngẫu nhiên — chương trình có thể crash ngay (undefined behavior). Khi chưa có địa chỉ hợp lệ, hãy gán int *p = nullptr; và chỉ giải tham chiếu *p sau khi p đã trỏ tới một biến thật.

TỔNG KẾT BÀI 10

  • &a lấy địa chỉ của biến a; *p trong biểu thức là giải tham chiếu — lấy giá trị tại địa chỉ p trỏ tới.
  • Khai báo con trỏ: int *p = &a; — kiểu phải khớp với kiểu biến mà nó trỏ tới.
  • Dùng *p = … có thể thay đổi giá trị biến gốc — vì cả hai cùng chỉ tới một ô nhớ.
  • Tên mảng hoạt động như con trỏ tới phần tử đầu: arr tương đương &arr[0]; *(p + i) tương đương p[i].
  • Truyền &a vào hàm để hàm nhận int *x và sửa được giá trị của a.
  • Đừng bao giờ giải tham chiếu con trỏ chưa trỏ tới đâu — dùng nullptr làm mặc định an toàn.
