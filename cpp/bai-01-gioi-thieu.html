Python đã dạy bạn tư duy lập trình; giờ là lúc bước vào thế giới của tốc độ. C++ là ngôn ngữ biên dịch đứng sau game (Unreal Engine), hệ điều hành và các kỳ thi thuật toán. Trong bài này bạn sẽ hiểu C++ là gì và cài đặt trình biên dịch để sẵn sàng gõ dòng code đầu tiên. ⚙️

C++ là gì?

C++ do Bjarne Stroustrup tạo ra năm 1985 tại Bell Labs, ban đầu là bản "nâng cấp" của ngôn ngữ C. Khác với Python — ngôn ngữ thông dịch (chạy từng dòng nhờ trình thông dịch) — C++ là ngôn ngữ biên dịch: bạn viết code, rồi compiler dịch toàn bộ chương trình thành mã máy trước khi nó chạy.

Chính vì được dịch thẳng sang mã máy, C++ chạy rất nhanh — đó là lý do nó được dùng cho game (Unreal Engine), hệ điều hành, trình duyệt và các kỳ thi đấu thuật toán.

Đây là file code C++ đầu tiên của bạn — để ý đuôi file .cpp:

hello.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "Hello from C++!" << endl;
    return 0;
}

Vì là ngôn ngữ biên dịch, file này chưa chạy được ngay — nó phải đi qua compiler trước. Lệnh biên dịch không in gì ra màn hình nghĩa là thành công, và một file chạy mới đã ra đời:

terminal 
g++ hello.cpp -o hello
ls

Cài đặt trình biên dịch

Viết C++ cần một trình biên dịch (compiler) — bộ công cụ phổ biến nhất là GCC, với lệnh g++. Cách cài tuỳ hệ điều hành:

  • Windows: cài MinGW-w64 (bộ GCC dành cho Windows) — cách gọn nhất là qua MSYS2; hoặc dùng Visual Studio Build Tools với gói "Desktop development with C++" nếu bạn thích bộ công cụ của Microsoft.
  • Ubuntu / Debian: mở terminal và chạy lệnh bên dưới.
  • macOS: chạy xcode-select --install để cài Xcode Command Line Tools (compiler trên macOS là clang++, nhưng gõ g++ vẫn hoạt động).

sudo apt install g++

Trên Windows, cài xong bạn còn phải thêm thư mục bin của compiler vào PATH rồi mở lại terminal. Nếu gõ g++ --version mà nhận thông báo kiểu 'g++' is not recognized... — gần như chắc chắn là compiler chưa nằm trong PATH.

Cuối cùng, cài VS Code và extension C/C++ (của Microsoft) để có gợi ý code, báo lỗi và format — đúng chuẩn dân lập trình. Gõ thử vài câu quiz để nhớ kỹ phần cài đặt nhé:

Biên dịch & chạy chương trình đầu tiên

Tạo file hello.cpp (trong VS Code: File ▸ New File rồi lưu với đuôi .cpp) và dán nội dung quen thuộc ở §1:

hello.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "Hello from C++!" << endl;
    return 0;
}

Giờ là nghi thức quan trọng nhất của mọi chương trình C++: biên dịch rồi chạy — hai bước tách biệt.

terminal 
g++ hello.cpp -o hello
./hello
▸ KẾT QUẢ 
Hello from C++!

Trước khi gõ, hãy giải phẫu lệnh biên dịch để hiểu mình đang làm gì:

Quên tùy chọn -o, compiler vẫn biên dịch nhưng đặt tên mặc định: a.out trên Linux/macOS (trên Windows là a.exe) — muốn chạy phải gõ ./a.out. Cứ dùng -o để đặt tên cho dễ nhớ!

TỔNG KẾT BÀI 01

  • C++ do Bjarne Stroustrup tạo ra năm 1985; là ngôn ngữ biên dịch — phải qua compiler thành mã máy trước khi chạy.
  • Nhanh là "vũ khí" chính: game (Unreal), hệ điều hành và thi đấu thuật toán đều dùng C++.
  • Cài compiler: Windows dùng MinGW-w64 (qua MSYS2) hoặc VS Build Tools; Ubuntu: sudo apt install g++; macOS: xcode-select --install.
  • Kiểm tra bằng g++ --version; trên Windows nhớ thêm compiler vào PATH và cài extension C/C++ cho VS Code.
  • Quy trình 2 bước: g++ hello.cpp -o hello (biên dịch) rồi ./hello (chạy). Quên -o → file mặc định a.out.
