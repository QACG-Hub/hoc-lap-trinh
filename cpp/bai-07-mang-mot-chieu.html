Mảng một chiều

[ NHIỆM VỤ #07 ] Chương 3 — Hàm & mảng Mức độ: Chiến binh

Một biến chỉ giữ được một giá trị — vậy 100 điểm của lớp thì sao? Mảng một chiều là dãy các ô nhớ liền nhau, mỗi ô đánh một số thứ tự (chỉ số) và cùng chứa một kiểu dữ liệu. Học xong bài này, bạn đủ sức duyệt mảng, tính tổng và tìm phần tử lớn nhất — bộ kỹ năng nền tảng cho mọi kỳ thi thuật toán. 🧩

Khai báo mảng

Mảng giống một dãy hộp số gắn liền nhau: khai báo một lần với số ô cố định, rồi truy cập từng ô qua chỉ số. Điều quan trọng nhất cần khắc cốt: chỉ số bắt đầu từ 0, không phải 1.

khai-bao-mang.cpp 
#include <iostream>
using namespace std;

int main() {
    int a[5] = {1, 2, 3, 4, 5};
    cout << a[0] << endl;   // phần tử ĐẦU TIÊN
    cout << a[4] << endl;   // phần tử CUỐI CÙNG
    return 0;
}
▸ KẾT QUẢ 
1
5

Mảng 5 phần tử mang chỉ số 0, 1, 2, 3, 4 — phần tử cuối là a[4] chứ không phải a[5]. Bạn cũng có thể khai báo trước rồi gán giá trị từng ô:

gan-tung-o.cpp 
#include <iostream>
using namespace std;

int main() {
    int a[3];          // 3 phần tử chưa có giá trị
    a[0] = 10;
    a[1] = 20;
    a[2] = 30;
    cout << a[1] << endl;
    return 0;
}
▸ KẾT QUẢ 
20

Giải phẫu cách "mở ô" trong mảng:

Truy cập vượt biên (ví dụ a[5] với mảng 5 phần tử) sẽ không báo lỗi khi biên dịch. Chương trình vẫn "chạy", nhưng đọc ra vùng nhớ bên cạnh mảng — giá trị rác, kết quả sai, thậm chí crash. Luôn nhớ: mảng n phần tử chỉ có chỉ số 0 đến n - 1. C++ tin bạn — nhưng máy thì không cảnh báo đâu!

Duyệt & tính toán

Điều kỳ diệu của mảng nằm ở chỗ: chỉ cần một vòng for, bạn xử lý cả dãy. Biến i đóng vai trò chỉ số chạy từ 0 đến n - 1. Trước tiên là nhập mảng từ bàn phím:

nhap-mang.cpp 
#include <iostream>
using namespace std;

int main() {
    int a[3];
    cout << "Nhập 3 số: ";
    for (int i = 0; i < 3; i++) {
        cin >> a[i];
    }
    cout << "Số thứ hai là: " << a[1] << endl;
    return 0;
}
▸ KẾT QUẢ 
Nhập 3 số: 10 20 30
Số thứ hai là: 20

Giải phẫu "mẫu duyệt mảng" — bạn sẽ gõ khung này hàng trăm lần:

Mẫu duyệt và mẫu nhập mảng dùng chung một khung for — chỉ khác lệnh bên trong (cin >> a[i]; để nhập, cout << a[i]; để in). Mẫu "cộng dồn" cũng vậy: tạo int tong = 0; trước vòng lặp, rồi tong += a[i]; bên trong — kết hợp cả vòng lặp lẫn biến tích luỹ của bài 5.

Xem cả dãy đi qua một vòng for — tính tổng và trung bình:

tong-trung-binh.cpp 
#include <iostream>
using namespace std;

int main() {
    int a[5] = {2, 4, 6, 8, 10};
    int tong = 0;
    for (int i = 0; i < 5; i++) {
        tong += a[i];
    }
    cout << "Tổng: " << tong << endl;
    cout << "Trung bình: " << (double)tong / 5 << endl;
    return 0;
}
▸ KẾT QUẢ 
Tổng: 30
Trung bình: 6

Tìm max & tìm kiếm

Hai thuật toán "vỡ lòng" trên mảng: tìm giá trị lớn nhất và tìm vị trí một phần tử. Cả hai đều đi qua từng ô và so sánh — chỉ khác cách "nắm giữ" kết quả:

tim-max.cpp 
#include <iostream>
using namespace std;

int main() {
    int a[6] = {4, 9, 2, 15, 7, 3};
    int lonNhat = a[0];             // giả sử ô đầu tiên là lớn nhất
    for (int i = 1; i < 6; i++) {   // xét từ ô thứ hai
        if (a[i] > lonNhat) {
            lonNhat = a[i];         // tìm được "vua" mới
        }
    }
    cout << "Lớn nhất: " << lonNhat << endl;
    return 0;
}
▸ KẾT QUẢ 
Lớn nhất: 15

Muốn biết phần tử nằm ở vị trí nào, ta in i khi giá trị khớp — và có thể break vì tìm thấy rồi:

tim-vi-tri.cpp 
#include <iostream>
using namespace std;

int main() {
    int a[6] = {4, 9, 2, 15, 7, 3};
    int x = 15;
    for (int i = 0; i < 6; i++) {
        if (a[i] == x) {
            cout << "Tìm thấy tại vị trí " << i << endl;
            break;
        }
    }
    return 0;
}
▸ KẾT QUẢ 
Tìm thấy tại vị trí 3

Vì sao khởi tạo lonNhat = a[0] mà không phải lonNhat = 0? Với mảng toàn số âm như {-5, -2, -9}, số 0 lớn hơn mọi phần tử nên đáp án sẽ sai thành 0. Lấy chính một phần tử làm mốc xuất phát thì "vua" luôn là thành viên thật của mảng. Tìm kiếm cũng cần nhớ: chỉ số tìm được là vị trí trong mảng (tính từ 0), không phải thứ tự đếm từ 1.

TỔNG KẾT BÀI 07

  • Mảng một chiều chứa nhiều giá trị cùng kiểu trong các ô liền nhau: int a[5] = {1, 2, 3, 4, 5};.
  • Chỉ số bắt đầu từ 0: mảng n phần tử có chỉ số hợp lệ 0 .. n - 1; a[0] là ô đầu tiên.
  • Truy cập vượt biên không bị báo lỗi khi biên dịch — chỉ đọc giá trị rác, cực kỳ nguy hiểm.
  • Mẫu duyệt mảng: for (int i = 0; i < n; i++) rồi dùng a[i]; nhập bằng cin >> a[i];.
  • Tính tổng bằng biến tích luỹ: tong = 0; rồi tong += a[i]; trong vòng lặp.
  • Tìm max: khởi tạo lonNhat = a[0] (không phải 0) rồi duyệt so sánh a[i] > lonNhat.
  • Tìm kiếm: so sánh a[i] == x, in chỉ số i khi tìm thấy — có thể break ngay.
