Còn vector giống một đoàn tàu — bạn cứ nối thêm toa mới vào cuối, không cần biết trước sẽ có bao nhiêu toa. Đây là cấu trúc dữ liệu được dùng nhiều nhất trong C++ hiện đại, và cũng là "tấm vé" bước vào thư viện chuẩn STL. ⚡

Vector cơ bản

vector là mảng động: tự co giãn khi bạn thêm hay bớt phần tử. Muốn dùng, chỉ cần nạp thêm thư viện <vector>:

vector.cpp 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;              // vector rỗng — chưa có phần tử nào
    v.push_back(3);             // thêm 3 vào cuối
    v.push_back(7);             // thêm 7 vào cuối
    v.push_back(5);             // thêm 5 vào cuối
    cout << v.size() << endl;   // đếm số phần tử
    cout << v[0] << endl;       // phần tử đầu tiên
    cout << v[2] << endl;       // phần tử cuối (chỉ số 2)
    return 0;
}

Duyệt vector

Vector có size() nên duyệt bằng vòng for theo chỉ số y hệt mảng. Nhưng STL còn tặng ta một món quà dễ thương hơn: range-based for — đọc là "với từng x trong v":

duyet-vector.cpp 
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v = {3, 7, 5};

    for (int i = 0; i < (int)v.size(); i++) {
        if (i > 0) cout << " ";
        cout << v[i];
    }
    cout << endl;

    for (int x : v) cout << x << endl;

    cout << "Dau: " << v.front() << ", Cuoi: " << v.back() << endl;
    v.pop_back();                // bỏ phần tử cuối
    cout << "Size sau pop_back: " << v.size() << endl;
    return 0;
}

for (int x : v) tạo ra bản sao của từng phần tử — sửa x không ảnh hưởng vector. Muốn sửa thật, viết for (int &x : v) (thêm dấu & — mượn trực tiếp, không sao chép). Ngoài ra: size() đếm phần tử, front() lấy phần tử đầu, back() lấy phần tử cuối, pop_back() xoá phần tử cuối.

Sắp xếp với sort

Vector lộn xộn {7, 3, 5}? STL có sẵn "cây gậy thần" sort trong thư viện <algorithm>. Chỉ một dòng lệnh là cả dãy xếp hàng ngay ngắn theo thứ tự tăng dần:

sort-vector.cpp 
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> v = {7, 3, 5};
    cout << "Truoc:";
    for (int x : v) cout << " " << x;
    cout << endl;

    sort(v.begin(), v.end());    // sắp xếp tăng dần

    cout << "Sau:";
    for (int x : v) cout << " " << x;
    cout << endl;
    return 0;
}
▸ KẾT QUẢ 
Truoc: 7 3 5
Sau: 3 5 7

v.begin() là "cổng vào" và v.end() là "cổng ra" của vector — hai iterator này nói cho sort biết cần sắp xếp toàn bộ vector. Bạn sẽ gặp lại cặp begin()/end() này rất nhiều lần khi làm việc với STL.

// GHI NHỚ

sort mặc định sắp tăng dần. Muốn giảm dần, cách nhẹ nhàng nhất là sắp tăng rồi reverse(v.begin(), v.end()); (cũng nằm trong <algorithm>). Và nhớ: thiếu #include <algorithm> là compiler đỏ lè ngay!

TỔNG KẾT BÀI 16

  • vector<int> v; là mảng động — thêm bao nhiêu phần tử cũng được; cần #include <vector>.
  • v.push_back(x) thêm phần tử vào cuối; v.size() đếm số phần tử; v[i] truy cập theo chỉ số (bắt đầu từ 0).
  • v.front() / v.back() lấy phần tử đầu / cuối; v.pop_back() bỏ phần tử cuối.
  • Duyệt vector: vòng for theo chỉ số (i < (int)v.size()) hoặc range-based for (int x : v); dùng int &x nếu muốn sửa phần tử.
  • sort(v.begin(), v.end()) sắp xếp tăng dần — cần #include <algorithm>.
  • Vector là "viên gạch đầu tiên" của STL — các bài sau: string, pair, map, set. 🚀
