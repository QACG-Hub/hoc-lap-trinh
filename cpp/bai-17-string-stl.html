String trong STL

[ NHIỆM VỤ #17 ] Chương 6 — STL & nâng cao Mức độ: Cao thủ

Bạn đã biết string từ bài chuỗi — nhưng đó mới là phần nổi của tảng băng. string trong STL là một con dao đa năng: đo độ dài, cắt, tìm, thay thế, chuyển qua lại giữa số và chữ... Nắm hết bộ kỹ năng này, bạn xử lý dữ liệu văn bản nhẹ như chơi game. Đây cũng là "hậu phương" tiếp lương cho bài dự án cuối khóa! ⚡

String sâu hơn

string biết chiều dài của chính nó, truy cập được từng ký tự như mảng, ghép thêm bằng += và so sánh bằng == như số bình thường:

string-co-ban.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "Xin chao";
    cout << s.length() << endl;              // số ký tự
    cout << s[0] << endl;                    // ký tự đầu: X
    s += " C++";                             // ghép thêm vào cuối
    cout << s << endl;
    cout << (s == "Xin chao C++") << endl;    // so sánh → 1 (đúng)
    return 0;
}

substr, find & replace

Ba hàm "thợ thủ công" của string: substr để cắt một đoạn, find để dò vị trí và replace để thay đoạn cũ bằng đoạn mới:

cat-tim-thay.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "hoc-lap-trinh";
    cout << s.substr(0, 3) << endl;    // cắt 3 ký tự từ vị trí 0
    cout << s.find("-") << endl;       // dò vị trí dấu gạch đầu tiên
    s.replace(0, 3, "HOC");           // thay "hoc" bằng "HOC"
    cout << s << endl;
    return 0;
}

find không tìm thấy sẽ trả về string::npos — một số khổng lồ, không phải -1. Đừng lấy thẳng kết quả find làm chỉ số cho substr/replace mà chưa kiểm tra: hãy viết if (s.find(x) != string::npos) { ... }. Cắt quá tay (substr(100, 3) khi chuỗi ngắn) cũng làm chương trình báo lỗi out_of_range ngay.

stoi & getline

Dữ liệu nhập từ bàn phím luôn là chuỗi. Hai "cầu nối" bạn sẽ dùng mỗi ngày: stoi đổi chuỗi thành số nguyên, còn getline đọc trọn một dòng — kể cả dấu cách:

stoi-getline.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string so = "123";
    int n = stoi(so);             // "123" → 123
    cout << n + 1 << endl;

    string hoTen;
    getline(cin, hoTen);          // đọc CẢ DÒNG, giữ cả dấu cách
    cout << "Chao " << hoTen << "!" << endl;
    return 0;
}

TỔNG KẾT BÀI 17

  • s.length() (hay s.size()) đếm số ký tự, kể cả dấu cách; truy cập ký tự bằng s[i] (từ 0).
  • Ghép chuỗi bằng += hoặc +; so sánh nội dung bằng ==, != — không cần hàm phụ trợ.
  • s.substr(pos, len) cắt một đoạn chuỗi mới; s.find(x) dò vị trí (không thấy trả về string::npos).
  • s.replace(pos, len, moi) thay len ký tự từ vị trí pos bằng chuỗi mới.
  • stoi(chuoi) đổi chuỗi số thành int; getline(cin, dong) đọc cả dòng văn bản.
  • Điều đáng nhớ nhất: cin >> rồi getline → phải cin.ignore(); ở giữa!
