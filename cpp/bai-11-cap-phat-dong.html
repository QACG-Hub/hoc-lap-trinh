Cấp phát động: new & delete

[ NHIỆM VỤ #11 ] Chương 4 — Con trỏ & bộ nhớ Mức độ: Cao thủ

Mảng thường có kích thước "đóng đinh" lúc biên dịch: muốn mảng 100 phần tử thì phải ghi 100 ngay trong code. Nhưng nếu số phần tử chỉ biết sau khi hỏi người dùng thì sao? Câu trả lời là cấp phát động với new — tự xin bộ nhớ lúc chạy, và delete để trả lại. Đây là sức mạnh thật sự của con trỏ! ⚡

new & delete

new int(5) xin hệ điều hành một ô nhớ vừa đủ chứa một số int, khởi tạo giá trị 5, và trả về địa chỉ của ô nhớ đó — nên phải hứng bằng con trỏ. Khi xong việc, gọi delete để trả ô nhớ về:

new-delete.cpp 
#include <iostream>
using namespace std;

int main() {
    int *p = new int(5);   // xin cấp phát 1 biến int, khởi tạo giá trị 5
    cout << *p << endl;    // đọc giá trị qua con trỏ
    *p = 42;               // ghi đè thoải mái như biến thường
    cout << *p << endl;
    delete p;              // trả lại bộ nhớ cho hệ thống
    return 0;
}

// CẢNH BÁO

Quên delete sau khi new gây rò rỉ bộ nhớ (memory leak): vùng nhớ vẫn bị chiếm nhưng bạn đã mất con trỏ để với tới nó. Với chương trình nhỏ thì khó thấy, nhưng vòng lặp new cả triệu lần mà quên delete thì máy sẽ "no bộ nhớ" và chết. Quy tắc: new ở đâu, delete ở đó.

Mảng động

Đây là lúc new toả sáng: cấp phát mảng với kích thước nhập từ bàn phím. Cú pháp là new int[n] — và mảng động dùng y như mảng thường, qua chỉ số arr[i]:

mang-dong.cpp 
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;                          // nhập số phần tử
    int *arr = new int[n];             // cấp phát mảng động n phần tử

    for (int i = 0; i < n; i++) cin >> arr[i];
    for (int i = 0; i < n; i++) cout << arr[i] << endl;

    delete[] arr;                      // giải phóng CẢ mảng bằng delete[]
    return 0;
}

Chú thích nhỏ: dòng 3 và dòng 7 8 9 là phần bạn gõ (số phần tử, rồi các phần tử); bốn dòng cuối là chương trình in ra — mỗi phần tử một dòng.

// CẢNH BÁO

Mảng cấp bằng new int[n] phải giải phóng bằng delete[] arr; (có ngoặc vuông), không phải delete arr;. Dùng sai có thể hỏng bộ nhớ hoặc crash — đây là lỗi khó tìm bậc nhất của C++. Quy tắc nhớ: xoá mảng thì delete[], xoá một biến thì delete.

// GHI NHỚ

Điểm "ăn tiền" của mảng động: n có thể nhập lúc chạy — mảng 5 phần tử hay 500 phần tử đều dùng một đoạn code. Mảng thường int arr[100]; thì phải ghi cứng kích thước và luôn tốn bấy nhiêu bộ nhớ.

TỔNG KẾT BÀI 11

  • new int(5) cấp phát MỘT biến int trên vùng nhớ động, khởi tạo 5; hứng địa chỉ bằng con trỏ int *p.
  • delete p; trả vùng nhớ về hệ thống — quên delete là rò rỉ bộ nhớ (new ở đâu, delete ở đó).
  • new int[n] cấp phát mảng động n phần tử; dùng như mảng thường qua chỉ số arr[i].
  • Giải phóng mảng phải dùng delete[] arr; — thiếu ngoặc vuông là hành vi không xác định.
  • Phân biệt: new int(5) là một biến = 5, còn new int[5] là mảng 5 phần tử.
  • Khác với mảng thường, kích thước mảng động có thể nhập từ bàn phím ngay lúc chạy chương trình.
