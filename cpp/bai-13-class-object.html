Class & Object

[ NHIỆM VỤ #13 ] Chương 5 — Lập trình hướng đối tượng Mức độ: Chiến binh

Nếu struct là "hộp dữ liệu" thụ động, thì class là cỗ máy mini: chứa cả dữ liệu lẫn những hàm hành động. Từ đây bạn bước vào tư duy lập trình hướng đối tượng (OOP) — cách tổ chức code mà mọi dự án lớn đều dùng. Trước khi vào bài: class là bản thiết kế, object là sản phẩm đúc ra từ bản thiết kế đó. ⚡

class & public

Từ khóa class tạo một "bản thiết kế" mới, gồm các thuộc tính (dữ liệu) và phương thức (hàm). Muốn code bên ngoài dùng được các thành viên, ta mở "cửa" bằng nhãn public:. Cùng xem lớp HocSinh đầu tiên:

hocsinh.cpp 
#include <iostream>
#include <string>
using namespace std;

class HocSinh {
public:
    string ten;
    int diem;
};

int main() {
    HocSinh hs;        // tạo object từ class
    hs.ten = "An";
    hs.diem = 9;
    cout << hs.ten << " - " << hs.diem << " diem" << endl;
    return 0;
}
▸ KẾT QUẢ 
An - 9 diem

Giải phẫu "bản thiết kế" — chú ý nhãn public: khác gì struct:

Quên nhãn public: là bẫy số một của class. Khác với struct, mọi thành viên của class mặc định là private — code bên ngoài truy cập sẽ bị compiler chặn ngay: error: 'ten' is private within this context. Thấy lỗi "private" hãy thêm public: vào đầu danh sách thuộc tính.

// GHI NHỚ

Về khả năng, struct và class gần như giống hệt nhau. Chúng chỉ khác mặc định: thành viên struct mặc định public, còn class mặc định private. Người C++ thường dùng struct cho "hộp dữ liệu" đơn giản, class cho thứ có hành động phức tạp.

Phương thức

Phương thức (member function) chỉ là hàm nằm bên trong class. Điều hay ho: nó dùng được trực tiếp các thuộc tính của chính object đang gọi — không cần truyền tham số lằng nhằng. Hãy xem lớp HinhChuNhat tự tính diện tích:

hinhchunhat.cpp 
#include <iostream>
using namespace std;

class HinhChuNhat {
public:
    int dai;
    int rong;

    int dienTich() {          // phương thức: hàm nằm trong class
        return dai * rong;    // dùng luôn thuộc tính của chính object
    }
};

int main() {
    HinhChuNhat a, b;             // hai object cùng class
    a.dai = 5;  a.rong = 3;
    b.dai = 4;  b.rong = 6;
    cout << "a: " << a.dienTich() << endl;   // 5 * 3
    cout << "b: " << b.dienTich() << endl;   // 4 * 6
    return 0;
}
▸ KẾT QUẢ 
a: 15
b: 24

Giải phẫu một phương thức — cấu trúc giống hàm, nhưng sống trong class:

Mỗi object có dữ liệu riêng: a giữ 5×3, b giữ 4×6 — cùng một class nhưng giá trị độc lập. Gọi a.dienTich() thì dai, rong bên trong phương thức chính là của a. Giống hai chiếc máy cùng model nhưng mỗi chiếc chứa nguyên liệu khác nhau.

TỔNG KẾT BÀI 13

  • class là "bản thiết kế" gồm thuộc tính (dữ liệu) và phương thức (hàm); object là biến được tạo từ class.
  • Thành viên class mặc định là private — muốn dùng từ bên ngoài phải mở "cửa" bằng public:.
  • Tạo object: HocSinh hs; — truy cập thành viên bằng dấu chấm: hs.ten, hs.diem.
  • Phương thức là hàm nằm trong class, dùng trực tiếp thuộc tính của object; gọi bằng h.dienTich().
  • Mỗi object giữ dữ liệu riêng dù cùng class: a là 5×3, b là 4×6, kết quả độc lập nhau.
  • struct vs class: khác nhau ở mặc định truy cập (public vs private) — còn lại gần như tương đương.
