Vòng lặp for, while, do-while

[ NHIỆM VỤ #05 ] Chương 2 — Cấu trúc điều khiển Mức độ: Chiến binh

Máy tính sinh ra để làm việc lặp đi lặp lại mà không biết mệt. Trong nhiệm vụ này bạn sẽ điều khiển vòng lặp: for khi biết trước số lần, while khi lặp theo điều kiện, do-while khi muốn chạy ít nhất một lần — kèm hai "phanh khẩn cấp" break và continue. 🔁

Vòng lặp for

Khi biết chính xác cần lặp bao nhiêu lần, for là lựa chọn số một. Nó gom cả ba việc — khởi tạo biến đếm, kiểm tra điều kiện, tăng biến đếm — vào một dòng duy nhất:

for-co-ban.cpp 
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 5; i++) {
        cout << i << endl;
    }
    return 0;
}

i++ là cách viết ngắn của i = i + 1 — tăng lên 1 sau mỗi vòng. Muốn đếm ngược thì giảm bằng i--:

dem-nguoc.cpp 
#include <iostream>
using namespace std;

int main() {
    for (int i = 5; i >= 1; i--) {
        cout << i << endl;
    }
    cout << "Phóng!" << endl;
    return 0;
}

Vòng lặp while

while chỉ quan tâm một điều kiện: chừng nào điều kiện còn đúng thì cứ lặp. Bạn tự viết phần khởi tạo trước vòng lặp và tự tăng biến đếm bên trong:

while-co-ban.cpp 
#include <iostream>
using namespace std;

int main() {
    int i = 1;              // khởi tạo trước
    while (i <= 5) {
        cout << i << endl;
        i++;                // nhớ tăng, nếu không sẽ lặp mãi!
    }
    cout << "Kết thúc, i = " << i << endl;
    return 0;
}

Quên i++ trong while là "tai nạn" đầu tiên của mọi người mới học: điều kiện i <= 5 mãi mãi đúng, chương trình in số 1 không ngừng và bạn phải bấm Ctrl + C để thoát. Mẹo phòng thân: viết i++ ngay khi gõ điều kiện, trước cả khi viết phần thân.

do-while & break/continue

do-while là người anh em "chắc chắn chạy" của while: nó thực hiện thân vòng lặp trước, rồi mới kiểm tra điều kiện. Nghĩa là thân vòng lặp luôn chạy ít nhất một lần:

do-while.cpp 
#include <iostream>
using namespace std;

int main() {
    int dem = 10;
    do {
        cout << "Chạy một lần" << endl;
        dem++;
    } while (dem < 5);
    return 0;
}

Chạy một lần

Điều kiện dem < 5 sai ngay từ đầu (10 không nhỏ hơn 5), vậy mà khối lệnh vẫn chạy một lần — đó là "chữ ký" của do-while. Giải phẫu:

🔬 GIẢI PHẪU CÚ PHÁP
do { ... } while (dem < 5);
Thành phầnÝ nghĩaBắt buộc
domở đầu — thân vòng lặp chạy trước, không cần điều kiện✅
{ ... }thân vòng lặp — LUÔN chạy ít nhất một lần✅
while (dem < 5)điều kiện — kiểm tra SAU mỗi vòng; đúng thì quay lại chạy tiếp✅
; cuối cùngdấu chấm phẩy sau while là BẮT BUỘC — khác hẳn while thường✅
// CẢNH BÁO

Vì kiểm tra điều kiện sau khi chạy, do-while luôn chạy ít nhất 1 lần — kể cả khi điều kiện sai ngay từ đầu. Đừng dùng nó khi muốn "điều kiện sai thì không chạy gì cả" (lúc đó dùng while); ngược lại, nó cực hợp cho menu nhập lựa chọn — luôn phải hiện menu ít nhất một lần. Và đừng quên dấu ; sau while (...) của do-while nhé!

Hai "phanh" giúp bạn kiểm soát vòng lặp: break thoát khỏi vòng lặp ngay lập tức, còn continue bỏ qua phần còn lại của vòng hiện tại để sang vòng kế tiếp:

break-continue.cpp 
#include <iostream>
using namespace std;

int main() {
    for (int i = 1; i <= 10; i++) {
        if (i == 3) continue;   // bỏ qua số 3
        if (i == 6) break;      // dừng hẳn khi gặp 6
        cout << i << endl;
    }
    cout << "Hết vòng lặp" << endl;
    return 0;
}

TỔNG KẾT BÀI 05

  • for (khởi_tạo; điều_kiện; cập_nhật) { ... } — dùng khi biết trước số lần lặp; i++ tăng, i-- giảm.
  • while (điều_kiện) { ... } — kiểm tra điều kiện trước mỗi vòng; điều kiện sai ngay từ đầu thì không chạy lần nào.
  • Trong while phải tự thay đổi giá trị trong thân vòng lặp (nhớ i++), nếu không sẽ lặp vô hạn.
  • do { ... } while (điều_kiện); — chạy ít nhất 1 lần, kiểm tra điều kiện sau; đừng quên dấu ; cuối.
  • break thoát vòng lặp ngay; continue bỏ qua phần còn lại của vòng hiện tại.
  • Mọi vòng for đều viết lại được bằng while — chọn cái nào dễ đọc hơn.
