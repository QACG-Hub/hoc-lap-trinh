Mảng hai chiều

[ NHIỆM VỤ #08 ] Chương 3 — Hàm & mảng Mức độ: Cao thủ

Mảng một chiều giống một dãy tủ lockers một hàng. Còn mảng hai chiều giống một bảng Excel có hàng có cột — nơi bạn ghi điểm từng môn của cả lớp, hay bản đồ một màn game. Nhiệm vụ hôm nay: khai báo, truy cập, in ra dạng bảng và tính toán trên cả ma trận bằng hai vòng for lồng nhau. ⚡

Khai báo & truy cập

Mảng hai chiều thực chất là mảng của các mảng: mỗi hàng là một mảng con. Khai báo bằng hai cặp ngoặc vuông [số hàng][số cột]:

mang2c.cpp 
#include <iostream>
using namespace std;

int main() {
    int b[2][3] = {{1, 2, 3}, {4, 5, 6}};
    cout << b[0][1] << endl;   // hàng 0, cột 1
    cout << b[1][2] << endl;   // hàng 1, cột 2
    b[0][0] = 99;              // đổi giá trị như biến thường
    cout << b[0][0] << endl;
    return 0;
}
▸ KẾT QUẢ 
2
6
99

Giải phẫu cú pháp khai báo — nhìn kỹ vì mọi thứ xoay quanh hai cặp ngoặc vuông:

Muốn in cả bảng cho dễ nhìn, ta cần hai vòng for lồng nhau: vòng ngoài chạy theo hàng, vòng trong chạy theo cột:

in-bang.cpp 
#include <iostream>
using namespace std;

int main() {
    int b[2][3] = {{1, 2, 3}, {4, 5, 6}};
    for (int i = 0; i < 2; i++) {
        for (int j = 0; j < 3; j++) {
            if (j > 0) cout << " ";
            cout << b[i][j];
        }
        cout << endl;   // hết một hàng thì xuống dòng
    }
    return 0;
}
▸ KẾT QUẢ 
1 2 3
4 5 6
// CẢNH BÁO

Chỉ số hàng và cột đều đếm từ 0! Mảng b[2][3] có hàng 0, 1 và cột 0, 1, 2. Truy cập b[2][0] hay b[0][3] là tràn ra ngoài mảng — chương trình có thể chạy sai, thậm chí crash mà compiler không hề báo lỗi.

Duyệt & tính toán

Trong thực tế, dữ liệu thường do người dùng nhập vào. Vì mảng hai chiều là "mảng của các mảng", ta chỉ cần hai vòng for lồng để nhập từng phần tử theo đúng thứ tự hàng → cột.

nhap-xuat.cpp 
#include <iostream>
using namespace std;

int main() {
    int b[2][3];
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 3; j++)
            cin >> b[i][j];          // nhập lần lượt 6 số

    int tong = 0;
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 3; j++)
            tong += b[i][j];         // cộng dồn toàn bộ

    cout << "Tong: " << tong << endl;
    return 0;
}
▸ KẾT QUẢ 
1 2 3 4 5 6
Tong: 21

Chú thích nhỏ: dòng 1 2 3 4 5 6 là phần bạn gõ từ bàn phím, còn Tong: 21 mới là thứ chương trình in ra. Máy tính lặng lẽ cộng đúng 1+2+3+4+5+6 = 21.

Tổng theo từng hàng

Nếu muốn biết mỗi hàng có tổng bao nhiêu, hãy khởi tạo biến tổng bên trong vòng for ngoài — như vậy mỗi hàng có một biến tổng "mới tinh":

tong-hang.cpp 
#include <iostream>
using namespace std;

int main() {
    int b[2][3] = {{1, 2, 3}, {4, 5, 6}};
    for (int i = 0; i < 2; i++) {
        int s = 0;                  // tổng RIÊNG của hàng i
        for (int j = 0; j < 3; j++)
            s += b[i][j];
        cout << "Hang " << i << ": " << s << endl;
    }
    return 0;
}
▸ KẾT QUẢ 
Hang 0: 6
Hang 1: 15
// GHI NHỚ

Kích thước mảng phải biết trước khi biên dịch: int b[2][3] là cố định. Muốn mảng "co giãn" theo số người dùng nhập, C++ có mảng động với new — hẹn gặp ở Bài 11!

TỔNG KẾT BÀI 08

  • Mảng hai chiều khai báo bằng hai cặp ngoặc vuông: int b[2][3]; — 2 hàng, 3 cột.
  • Khởi tạo giá trị: int b[2][3] = {{1, 2, 3}, {4, 5, 6}}; — mỗi cặp {} là một hàng.
  • Truy cập phần tử: b[hang][cot]; chỉ số đếm từ 0 nên hàng hợp lệ là 0..1, cột là 0..2.
  • Duyệt toàn mảng cần hai vòng for lồng nhau: vòng ngoài theo hàng, vòng trong theo cột.
  • Tổng toàn bộ: khởi tạo tong = 0 trước cả hai vòng; tổng từng hàng: khởi tạo lại s = 0 trong vòng ngoài.
  • Truy cập quá chỉ số (như b[2][0]) không báo lỗi biên dịch nhưng cực kỳ nguy hiểm — nhớ đúng phạm vi!
