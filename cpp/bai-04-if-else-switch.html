Rẽ nhánh if / else & switch

[ NHIỆM VỤ #04 ] Chương 2 — Cấu trúc điều khiển Mức độ: Chiến binh

Từ bài này, chương trình không còn chạy "thẳng một đường" nữa — nó biết ra quyết định. Bạn sẽ học cách cho máy chọn một trong hai hướng đi với if / else, xét nhiều mức với else if, kết hợp điều kiện bằng &&, ||, !, và dùng switch...case khi cần so sánh với nhiều giá trị cụ thể. ⚡

Rẽ nhánh với if / else

if / else giống như ngã rẽ trên đường đua: nếu điều kiện đúng thì rẽ nhánh này, sai thì đi nhánh kia. Hãy xem chương trình kiểm tra điểm đậu/rớt:

if-else.cpp 
#include <iostream>
using namespace std;

int main() {
    int diem = 7;
    if (diem >= 5) {
        cout << "Đậu rồi! Chúc mừng!" << endl;
    } else {
        cout << "Rớt rồi, cố lên nhé!" << endl;
    }
    return 0;
}

Đậu rồi! Chúc mừng!

Vì diem = 7 thỏa điều kiện diem >= 5 nên chỉ khối lệnh sau if chạy, khối else bị bỏ qua. Một điều thú vị: if không bắt buộc có else, và các lệnh nằm ngoài khối if thì luôn chạy:

if-don-gian.cpp 
#include <iostream>
using namespace std;

int main() {
    int nhietDo = 38;
    if (nhietDo > 37) {
        cout << "Sốt rồi!" << endl;
        cout << "Uống nhiều nước nhé." << endl;
    }
    cout << "Kiểm tra xong." << endl;   // luôn chạy
    return 0;
}

Giờ giải phẫu "ngã rẽ" này để nhớ từng mảnh ghép:

Đừng nhầm = (gán giá trị) với == (so sánh). Viết if (diem = 5) là gán 5 cho diem rồi coi giá trị đó là điều kiện — điều kiện "5" luôn được xem là ĐÚNG, nên nhánh if chạy bất chấp điểm thật. Compiler thường chỉ cảnh báo chứ không báo lỗi, nên lỗi này rất khó thấy. Hãy đọc lại: so sánh thì luôn dùng ==.

else if & điều kiện kết hợp

Đời không chỉ có hai lựa chọn. Muốn xếp loại Giỏi / Khá / Trung bình / Yếu, ta nối nhiều else if thành một thang điều kiện. Máy sẽ xét từ trên xuống, gặp điều kiện đúng đầu tiên thì chạy nhánh đó rồi thoát khỏi cả thang:

xep-loai.cpp 
#include <iostream>
using namespace std;

int main() {
    double diem = 7.5;
    if (diem >= 8) {
        cout << "Xếp loại: Giỏi" << endl;
    } else if (diem >= 6.5) {
        cout << "Xếp loại: Khá" << endl;
    } else if (diem >= 5) {
        cout << "Xếp loại: Trung bình" << endl;
    } else {
        cout << "Xếp loại: Yếu" << endl;
    }
    return 0;
}
▸ KẾT QUẢ 
Xếp loại: Khá

Điểm 7.5 không đạt >= 8 nhưng đạt >= 6.5 — nên dừng ở nhánh "Khá". Đôi khi một điều kiện là chưa đủ: vé vào rạp có thể do đủ tuổi hoặc có vé mời, còn điểm khá thì phải nằm trong khoảng 5–8 — ta kết hợp bằng && (VÀ), || (HOẶC), ! (phủ định):

ket-hop.cpp 
#include <iostream>
using namespace std;

int main() {
    int tuoi = 17;
    bool coVe = true;
    if (tuoi >= 18 || coVe) {          // đủ tuổi HOẶC có vé
        cout << "Được vào rạp!" << endl;
    } else {
        cout << "Không được vào." << endl;
    }

    int diem = 7;
    if (diem >= 5 && diem <= 8) {      // VÀ: phải nằm trong khoảng
        cout << "Điểm khá!" << endl;
    }

    bool troiMua = false;
    if (!troiMua) {                     // phủ định: trời KHÔNG mưa
        cout << "Đi chơi thôi!" << endl;
    }
    return 0;
}

Ba toán tử logic này là "bộ não" của mọi điều kiện phức tạp — giải phẫu chúng:

🔬 GIẢI PHẪU CÚ PHÁP
(diem >= 5) && (diem <= 8)
Thành phầnÝ nghĩaBắt buộc

Thang else if được xét từ trên xuống. Nếu đặt điều kiện rộng lên trước, các nhánh bên dưới sẽ không bao giờ chạy: if (diem >= 5) rồi else if (diem >= 8) thì mọi điểm từ 5 trở lên đều dính nhánh đầu. Hãy xếp từ khắt khe đến lỏng dần (Giỏi → Khá → Trung bình → Yếu).

switch...case

Khi cần so sánh một biến với nhiều giá trị cụ thể (chọn menu 1–2–3, in tên thứ trong tuần), viết chuỗi if / else if dài sẽ rối. switch...case là "bảng chọn" gọn gàng hơn:

menu.cpp 
#include <iostream>
using namespace std;

int main() {
    int chon = 2;
    switch (chon) {
        case 1:
            cout << "Xem điểm" << endl;
            break;
        case 2:
            cout << "Nộp bài" << endl;
            break;
        case 3:
            cout << "Thoát" << endl;
            break;
        default:
            cout << "Lựa chọn không hợp lệ" << endl;
    }
    return 0;
}
▸ KẾT QUẢ 
Nộp bài

Giải phẫu "bảng chọn" này — đặc biệt để ý chữ break:

🔬 GIẢI PHẪU CÚ PHÁP
switch (chon) { case 2: ... break; default: ... }
Thành phầnÝ nghĩaBắt buộc
switch (chon)biến/biểu thức cần so sánh (thường là int hoặc char)✅
case 2:nhãn giá trị — nếu chon == 2 thì chạy từ đây; kết thúc bằng dấu :✅ (ít nhất 1 case)
break;thoát khỏi switch — nếu thiếu sẽ "rơi" xuống case dưới❌ về cú pháp, ✅ về logic
default:chạy khi không case nào khớp — như nhánh else của switch❌ (nhưng nên có)

Hãy xem điều gì xảy ra khi quên break — lần này case 2 cố tình thiếu:

quen-break.cpp 
int x = 2;
switch (x) {
    case 1: cout << "Một" << endl;   break;
    case 2: cout << "Hai" << endl;   // thiếu break!
    case 3: cout << "Ba" << endl;    break;
    default: cout << "Khác" << endl;
}
▸ KẾT QUẢ 
Hai
Ba
// CẢNH BÁO

Quên break là "cú ngã" kinh điển của switch. Với x = 2, máy bắt đầu ở case 2, in "Hai" rồi vì thiếu break nên rơi tuột xuống case 3 in tiếp "Ba", gặp break mới dừng. Hãy coi mỗi case như một toa tàu: không có break thì tàu chạy sang toa kế tiếp. Trừ khi bạn cố ý gom nhiều case chung một xử lý, hãy kết thúc mỗi case bằng break;.

TỔNG KẾT BÀI 04

  • Rẽ nhánh hai hướng: if (điều_kiện) { ... } else { ... }; điều kiện BẮT BUỘC nằm trong ngoặc tròn.
  • So sánh dùng ==, !=, >, <, >=, <= — tuyệt đối không dùng = (phép gán) trong điều kiện.
  • Nhiều mức lựa chọn: nối else if thành thang, xét từ trên xuống — xếp điều kiện khắt khe trước để không "che" nhánh dưới.
  • Kết hợp điều kiện: && (VÀ), || (HOẶC), ! (phủ định).
  • switch (biến) { case giá_trị: ... break; default: ... } — gọn khi so sánh với nhiều giá trị cụ thể.
  • Quên break trong switch sẽ "rơi" xuống các case bên dưới — luôn kiểm tra lại!
