🎯 Nhiệm vụ cuối cùng của khóa C++ đã tới! Bạn sẽ ráp mọi mảnh ghép — struct, vector, hàm, vòng lặp, thống kê, xử lý file — thành một sản phẩm hoàn chỉnh: phần mềm quản lý điểm sinh viên chạy được, có menu, có lưu dữ liệu. Đây không phải bài học lý thuyết suông: cuối bài bạn sẽ tốt nghiệp với một dự án thật trong tay. Bắt đầu thôi! 🚀

Đề bài & thiết kế dữ liệu

Đề bài: viết chương trình quản lý điểm sinh viên với các chức năng:

  • Thêm sinh viên (tên, điểm Toán, điểm Văn) vào danh sách.
  • In danh sách vừa nhập.
  • Thống kê: điểm trung bình từng bạn, tìm bạn điểm cao nhất.
  • Lưu danh sách ra file để lần sau mở lại vẫn còn.

Bước thiết kế đầu tiên là chọn kiểu dữ liệu. Mỗi sinh viên có nhiều thông tin đi liền nhau (tên + điểm Toán + điểm Văn), nên ta gom vào một struct. Cả lớp là nhiều sinh viên → dùng vector (đã học bài 16, thêm bao nhiêu bạn cũng được):

thiet-ke-du-lieu.cpp 
#include <iostream>
#include <string>
#include <vector>
using namespace std;

struct SinhVien {
    string ten;
    double toan, van;
};

int main() {
    vector<SinhVien> ds;
    ds.push_back({"Nam", 8.5, 7});
    cout << ds[0].ten << ": " << ds[0].toan << endl;
    return 0;
}
▸ KẾT QUẢ 
Nam: 8.5

Giải phẫu "khuôn đúc" struct — mỗi biến kiểu SinhVien đúc ra sẽ có đủ ba ngăn dữ liệu:

Cặp bài trùng "struct + vector" là bộ khung của gần như mọi phần mềm quản lý: struct mô tả một đối tượng, vector chứa danh sách đối tượng. Truy cập dữ liệu bằng dấu chấm: ds[0].ten là tên của sinh viên đầu tiên, ds[0].toan là điểm Toán của bạn đó.

Thêm & in danh sách

Chương trình thật không viết hết vào main — ta tách thành từng hàm làm đúng một việc. Hai hàm đầu tiên: them (thêm sinh viên) và inDanhSach (in cả danh sách):

them-va-in.cpp 
void them(vector<SinhVien> &ds, string ten, double toan, double van) {
    ds.push_back({ten, toan, van});
}

void inDanhSach(const vector<SinhVien> &ds) {
    for (const SinhVien &sv : ds)
        cout << sv.ten << " | Toan: " << sv.toan
             << " | Van: " << sv.van << endl;
}

Giờ xem hai hàm này "chạy thật" trong main:

main.cpp 
int main() {
    vector<SinhVien> ds;
    them(ds, "Nam", 8.5, 7);
    them(ds, "Lan", 9, 9.5);
    inDanhSach(ds);
    return 0;
}
▸ KẾT QUẢ 
Nam | Toan: 8.5 | Van: 7
Lan | Toan: 9 | Van: 9.5

Để ý dấu & trong void them(vector<SinhVien> &ds, ...): nó nói rằng hàm nhận chính vector gốc — như mượn chìa khoá mở đúng chiếc tủ của main, thay vì nhận một bản photo rồi sửa lên bản photo đó. Còn trong inDanhSach, const ... & nghĩa là "mượn xem nhưng không được sửa" — vừa nhanh vừa an toàn.

// CẢNH BÁO

Viết thiếu dấu & — void them(vector<SinhVien> ds, ...) — chương trình vẫn biên dịch nhưng là một cái bẫy: hàm nhận bản sao, thêm sinh viên vào bản sao, rồi bản sao bị xoá khi hàm kết thúc. Danh sách trong main vẫn rỗng trơ và bạn ngồi ngơ ngác "sao in ra không có ai?" 😅

Thống kê điểm

Dữ liệu đã có, giờ là phần "ăn điểm" của dự án: tính điểm trung bình và tìm thủ khoa. Hàm tính điểm trung bình chỉ một dòng:

diem-tb.cpp 
double diemTB(const SinhVien &sv) {
    return (sv.toan + sv.van) / 2;
}

Tìm bạn điểm cao nhất thì dùng một vòng lặp + biến max — kỹ thuật quen thuộc từ chương mảng, nâng cấp lên đối tượng SinhVien:

thong-ke.cpp 
int main() {
    vector<SinhVien> ds;
    them(ds, "Nam", 8.5, 7);
    them(ds, "Lan", 9, 9.5);

    SinhVien caoNhat = ds[0];
    for (const SinhVien &sv : ds)
        if (diemTB(sv) > diemTB(caoNhat))
            caoNhat = sv;

    cout << "Diem TB cua Nam: " << diemTB(ds[0]) << endl;
    cout << "Cao nhat: " << caoNhat.ten << " (" << diemTB(caoNhat) << ")" << endl;
    return 0;
}
▸ KẾT QUẢ 
Diem TB cua Nam: 7.75
Cao nhat: Lan (9.25)

Cách tìm max: giả sử bạn đầu tiên là thủ khoa, rồi duyệt từng bạn — ai giỏi hơn "thủ khoa tạm thời" thì soán ngôi. Hết vòng lặp, caoNhat đúng là người điểm cao nhất. Nam được 7.75 còn Lan 9.25 — Lan thắng! 👑

// CẢNH BÁO

Khởi tạo SinhVien caoNhat = ds[0]; chỉ an toàn khi danh sách có ít nhất 1 người. Danh sách rỗng mà truy cập ds[0] là hành vi không xác định. Hãy kiểm tra if (ds.empty()) { cout << "Danh sach rong!"; return; } trước khi thống kê. Và đừng khởi tạo max bằng điểm 0 — lỡ cả lớp điểm âm thì "thủ khoa" thành bạn 0 điểm đó!

Hoàn thiện & mở rộng

Một chương trình "ra hồn" cần menu để người dùng chọn chức năng. Công thức kinh điển: while giữ chương trình chạy + switch rẽ nhánh theo lựa chọn:

menu.cpp 
int main() {
    vector<SinhVien> ds = {{"Nam", 8.5, 7}, {"Lan", 9, 9.5}};
    int chon;
    while (true) {
        cout << "1.Xem danh sach  0.Thoat: ";
        cin >> chon;
        switch (chon) {
            case 1: inDanhSach(ds); break;
            case 0: return 0;
            default: cout << "Chon sai, thu lai!" << endl;
        }
    }
}
▸ KẾT QUẢ 
1.Xem danh sach  0.Thoat: 1
Nam | Toan: 8.5 | Van: 7
Lan | Toan: 9 | Van: 9.5
1.Xem danh sach  0.Thoat: 0

Chú thích nhỏ: số 1 và 0 trong kết quả là phần bạn gõ từ bàn phím — chương trình in lời nhắc rồi chờ bạn nhập. Cuối cùng, "ông trùm" của dự án: lưu danh sách ra file để lần sau mở lại vẫn còn (ôn lại bài 19 nào):

luu-file.cpp 
void luuFile(const vector<SinhVien> &ds) {
    ofstream f("diem.txt");
    for (const SinhVien &sv : ds)
        f << sv.ten << " " << sv.toan << " " << sv.van << endl;
    f.close();
}

Sau khi gọi luuFile(ds);, file diem.txt sẽ chứa mỗi sinh viên một dòng: Nam 8.5 7, Lan 9 9.5... và bạn hoàn toàn có thể viết hàm docFile đọc ngược chúng vào lại vector để chương trình thật sự "nhớ lâu".

Gợi ý mở rộng để biến dự án thành sản phẩm riêng của bạn:

  • Thêm chức năng xóa / sửa sinh viên theo tên (gợi ý: tìm rồi dùng ds.erase(ds.begin() + i)).
  • Sắp xếp lớp theo điểm trung bình giảm dần — kết hợp sort (bài 16) với diemTB.
  • Thống kê thêm: điểm trung bình cả lớp, số bạn trên 8, điểm thấp nhất.
  • Đếm số lượng bằng map<string, int> (bài 18) khi dữ liệu phình to.
  • Lưu dạng CSV và mở bằng Excel — dữ liệu bạn ghi ra đã gần đúng chuẩn CSV rồi đấy!

Chúc mừng tốt nghiệp khóa C++! Từ dòng cout << "Hello, World!" đầu tiên, bạn đã đi qua biến, rẽ nhánh, vòng lặp, hàm, mảng, con trỏ, lập trình hướng đối tượng... và giờ là STL + dự án hoàn chỉnh. Bạn không còn là người "học cú pháp" nữa — bạn đã biết thiết kế chương trình.

  • Bộ ba dữ liệu của dự án: struct SinhVien (mô tả 1 bạn), vector<SinhVien> ds (cả danh sách), dấu . để truy cập trường.
  • Hàm nhận vector phải có & nếu muốn thay đổi dữ liệu; thêm dòng const nếu chỉ đọc.
  • Thống kê: diemTB(sv) tính trung bình; tìm max bằng vòng lặp + khởi tạo từ ds[0] (nhớ kiểm tra danh sách rỗng).
  • Chương trình hoàn thiện: menu while + switch, lưu file bằng ofstream, đọc lại bằng ifstream.
  • Tư duy mới bạn mang theo: chia chương trình thành hàm nhỏ — kiểu dữ liệu trước, thuật toán sau — luôn kiểm tra trường hợp biên.
  • Con đường phía trước: luyện giải thuật (sắp xếp, tìm kiếm, quy hoạch động), làm dự án cá nhân, đọc thêm tài liệu tại cppreference.com. Đỉnh cao không dành cho người dừng lại! ⚡
