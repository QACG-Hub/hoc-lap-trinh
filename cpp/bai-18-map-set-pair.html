Map, Set & Pair

[ NHIỆM VỤ #18 ] Chương 6 — STL & nâng cao Mức độ: Cao thủ

Vector giỏi giữ thứ tự, nhưng có những bài toán cần "tra cứu theo tên" như từ điển, hoặc "lọc trùng" như danh sách khách mời. Hôm nay bạn nhận bộ ba vũ khí mới của STL: pair (cặp giá trị), map (từ điển key–value) và set (tập hợp không trùng). Bộ ba này xuất hiện trong gần như mọi kỳ thi và dự án thực tế! ⚡

pair — cặp giá trị

pair là "hộp đựng" vừa đúng 2 thứ, hai ô có tên cố định là first và second. Nó như một thẻ học sinh ghi tên một bên, điểm một bên:

pair.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    pair<string, int> p = {"Nam", 9};
    cout << p.first << endl;            // thành phần thứ nhất
    cout << p.second << endl;           // thành phần thứ hai
    p.second = 10;                       // cập nhật điểm
    cout << p.first << ": " << p.second << endl;
    return 0;
}
▸ KẾT QUẢ 
Nam
9
Nam: 10

Giải phẫu khai báo — thứ tự hai kiểu trong < > quyết định kiểu của first và second:

pair cực hợp để gom "2 thứ đi liền nhau" — ví dụ vector<pair<string, int>> lưu danh sách tên–điểm. Bài sau bạn sẽ thấy map thực chất là "bộ sưu tập các pair" với mỗi phần tử là một cặp key–value, nên .first/.second quay lại ngay!

map — từ điển

map giống cuốn từ điển: tra theo key (khoá) để lấy value (giá trị). Mỗi key là duy nhất. Ở đây ta lập "bảng điểm các môn", khoá là tên môn, giá trị là điểm:

map.cpp 
#include <iostream>
#include <string>
#include <map>
using namespace std;

int main() {
    map<string, int> diem;
    diem["toan"] = 8;
    diem["van"] = 7;
    diem["anh"] = 9;

    cout << diem["toan"] << endl;
    diem["toan"] = 10;               // ghi đè giá trị cũ
    cout << diem["toan"] << endl;
    cout << diem.size() << endl;

    for (auto &m : diem)
        cout << m.first << ": " << m.second << endl;
    return 0;
}
▸ KẾT QUẢ 
8
10
3
anh: 9
toan: 10
van: 7

Để ý kết quả in ra: dù nhập toan trước, anh lại hiện đầu tiên — vì map tự sắp xếp theo key (thứ tự bảng chữ cái). Nhìn dòng duyệt: mỗi phần tử m là một pair, nên m.first là môn và m.second là điểm.

// CẢNH BÁO

Truy cập diem["ly"] khi key "ly" chưa tồn tại sẽ âm thầm tạo mới key đó với giá trị 0! Nếu chỉ muốn kiểm tra, hãy dùng diem.count("ly") (trả về 0 hoặc 1) hoặc diem.find("ly") != diem.end(). Đây là cái bẫy kinh điển khiến size() phình to bất thường.

set — tập hợp không trùng

set là tập hợp: thêm cùng một giá trị bao nhiêu lần cũng chỉ giữ một bản, và các phần tử luôn được xếp tăng dần. Cực hợp cho bài toán "lọc trùng danh sách":

set.cpp 
#include <iostream>
#include <set>
using namespace std;

int main() {
    set<int> s;
    s.insert(3);
    s.insert(1);
    s.insert(3);             // trùng — bị bỏ qua
    s.insert(7);

    cout << "Cac phan tu:";
    for (int x : s) cout << " " << x;
    cout << endl;
    cout << "So luong: " << s.size() << endl;
    return 0;
}
▸ KẾT QUẢ 
Cac phan tu: 1 3 7
So luong: 3

Bốn lần insert nhưng chỉ còn 3 phần tử — số 3 trùng đã bị tự loại. Và chú ý: các phần tử ra theo thứ tự tăng dần chứ không phải thứ tự chèn.

// GHI NHỚ

set không có chỉ số s[i] — muốn duyệt thì dùng range-based for với set<int> s. Muốn kiểm tra một giá trị có trong set không: s.count(x) trả về 1 nếu có, 0 nếu không. Muốn xoá một phần tử: s.erase(x).

TỔNG KẾT BÀI 18

  • pair<A, B> p = {x, y}; gom 2 giá trị: p.first kiểu A, p.second kiểu B.
  • map<K, V> m; là từ điển key–value; truy cập và gán bằng m[key]; key là duy nhất.
  • Duyệt map bằng range-based for: mỗi phần tử là một pair — .first là key, .second là value.
  • Map tự sắp xếp theo key; tra key lạ bằng m[key] sẽ tạo key mới giá trị 0 — kiểm tra bằng count/find.
  • set<T> s; là tập hợp không trùng, tự xếp tăng dần; thêm bằng s.insert(x), kiểm tra bằng s.count(x).
  • Bộ ba pair – map – set là công cụ tra cứu & lọc trùng trứ danh của STL — dùng ngay ở bài dự án nhé!
