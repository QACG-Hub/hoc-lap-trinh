Cấu trúc chương trình C++

Mọi chương trình C++ đều xoay quanh một hàm đặc biệt tên là main() — nơi máy bắt đầu thực thi. Hãy xem chương trình Hello World hoàn chỉnh, chạy được ngay bằng g++:

hello.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
▸ KẾT QUẢ 
Hello, World!

Chỉ 7 dòng nhưng có đủ "bộ khung" mà chương trình C++ nào cũng cần. Đọc từng dòng:

DòngÝ nghĩa
#include <iostream>nạp thư viện nhập/xuất — có nó mới dùng được cout, endl
using namespace std;cho phép viết ngắn cout thay vì std::cout
int main() { … }hàm chính — máy bắt đầu thực thi từ đây
cout << "Hello, World!" << endl;in chuỗi ra màn hình rồi xuống dòng
return 0;kết thúc main, trả mã 0 = "mọi thứ thành công"

Giờ giải phẫu dòng lệnh in — trái tim của chương trình này:

Quên dấu ; là lỗi kinh điển nhất của người mới học C++: compiler báo error: expected ';' before ... kèm số dòng cần sửa — cứ đọc kỹ rồi thêm vào. Mỗi câu lệnh đều kết thúc bằng dấu chấm phẩy, kể cả return 0;.

In ra màn hình với cout

cout là "loa phát thanh" của chương trình. Toán tử << đẩy dữ liệu về phía màn hình, và bạn có thể nối nhiều << trong cùng một lệnh để in nhiều thứ liên tiếp. Cái bẫy đầu tiên cũng giống hệt Python: có dấu nháy là chuỗi, không nháy là biểu thức.

so-sanh.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "2 + 3" << endl;            // chuỗi → in nguyên văn
    cout << 2 + 3 << endl;              // biểu thức → C++ tính trước
    cout << "Tong: " << 2 + 3 << endl;  // nối nhiều << trong một lệnh
    return 0;
}
▸ KẾT QUẢ 
2 + 3
5
Tong: 5

Một điều thú vị: cout chỉ xuống dòng khi bạn yêu cầu. Hãy xem hai lệnh in liên tiếp và hai cách xuống dòng thông dụng:

xuong-dong.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << "A";               // chưa xuống dòng...
    cout << "B" << endl;       // ...nên A và B dính liền nhau: AB
    cout << "Dòng 1" << endl;  // endl: xuống dòng và đẩy dữ liệu ra ngay
    cout << "Dòng 2" << "\n";  // "\n" trong chuỗi: cũng xuống dòng, gõ ngắn hơn
    return 0;
}
▸ KẾT QUẢ 
AB
Dòng 1
Dòng 2
// GHI NHỚ

cout và endl thực chất nằm trong namespace std — tên đầy đủ là std::cout, std::endl. Dòng using namespace std; cho phép viết tắt. Bỏ dòng đó đi thì phải viết std::cout << "Hi"; — vẫn chạy tốt, chỉ dài hơn.

Comment

Comment (ghi chú) là những phần C++ bỏ qua hoàn toàn khi biên dịch — dùng để giải thích code, đánh dấu việc cần làm hoặc tạm tắt một dòng lệnh. C++ có hai kiểu: // cho một dòng và /* … */ cho nhiều dòng.

comment.cpp 
#include <iostream>
using namespace std;

// Comment một dòng — bắt đầu bằng hai dấu gạch chéo

int main() {
    cout << "Dòng này chạy" << endl;   // ghi chú ngay sau lệnh cũng được

    /* Comment nhiều dòng:
       trải dài bao nhiêu dòng cũng được,
       kết thúc bằng dấu đóng */

    // cout << "Dòng này bị tắt" << endl;

    return 0;
}

TỔNG KẾT BÀI 02

  • Bộ khung chương trình C++: #include <iostream> → using namespace std; → int main() { … } → return 0;.
  • Máy luôn bắt đầu chạy từ hàm main(); mỗi câu lệnh kết thúc bằng dấu ;.
  • cout << … in ra màn hình; nối nhiều << trong một lệnh; chuỗi phải nằm trong nháy kép.
  • Có nháy → in nguyên văn; không nháy → C++ tính trước rồi in (giống print() của Python).
  • Xuống dòng bằng endl hoặc "\n"; không có gì thì các lệnh in dính liền nhau.
  • Comment: // một dòng, /* … */ nhiều dòng — không ảnh hưởng khi chạy.
