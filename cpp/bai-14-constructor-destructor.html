Constructor & Destructor

[ NHIỆM VỤ #14 ] Chương 5 — Lập trình hướng đối tượng Mức độ: Cao thủ

Ở bài trước, tạo object xong bạn phải tự gán từng thuộc tính — quên một cái là dữ liệu "rác" nằm luôn trong máy. C++ có hai "người quản gia" tự động: constructor dọn dẹp và nạp đồ lúc object sinh ra, destructor thu dọn lúc object ra đi. Học xong bài này, object của bạn sẽ "tự biết" mình cần gì. ⚡

Constructor

Constructor (hàm khởi tạo) là hàm đặc biệt cùng tên với class và không có kiểu trả về. Nó tự động chạy ngay khi object được tạo — bạn không gọi tên nó bao giờ. Xem lớp Point nhận toạ độ ngay lúc sinh ra:

point.cpp 
#include <iostream>
using namespace std;

class Point {
public:
    int x, y;

    Point(int a, int b) {   // constructor: tên trùng class
        x = a;
        y = b;
    }
};

int main() {
    Point p(3, 5);          // constructor tự chạy với a = 3, b = 5
    cout << "(" << p.x << ", " << p.y << ")" << endl;
    return 0;
}
▸ KẾT QUẢ 
(3, 5)

Giải phẫu constructor — ba đặc điểm "nhận diện" nằm ở đây:

Một class có thể có nhiều constructor khác bộ tham số — C++ tự chọn cái khớp với cách bạn tạo object. Rất tiện khi muốn có "object mặc định" lẫn "object nạp đầy đủ":

nhieu-ctor.cpp 
#include <iostream>
using namespace std;

class Point {
public:
    int x, y;

    Point() { x = 0; y = 0; }              // không tham số
    Point(int a, int b) { x = a; y = b; }  // có tham số

    void in() { cout << "(" << x << ", " << y << ")" << endl; }
};

int main() {
    Point p1;        // gọi Point()
    Point p2(4, 7);  // gọi Point(int, int)
    p1.in();
    p2.in();
    return 0;
}
▸ KẾT QUẢ 
(0, 0)
(4, 7)
// GHI NHỚ

Nếu bạn không viết constructor nào, C++ tự sinh một constructor mặc định rỗng — thuộc tính sẽ chứa giá trị "rác" không xác định. Vì vậy hãy tập thói quen tự viết constructor để object sinh ra là đã hợp lệ ngay.

Destructor

Destructor (hàm hủy) là "anh em sinh đôi" của constructor: tên class có thêm dấu ~ phía trước, không tham số, không kiểu trả về. Nó cũng tự chạy — nhưng vào lúc object hết phạm vi, tức là bị "thu hồi". Cùng xem thứ tự sinh ra và ra đi của một object:

huy.cpp 
#include <iostream>
using namespace std;

class Point {
public:
    int x, y;

    Point(int a, int b) {
        x = a; y = b;
        cout << "Tạo Point (" << x << ", " << y << ")" << endl;
    }
    ~Point() {
        cout << "Đã hủy Point (" << x << ", " << y << ")" << endl;
    }
};

int main() {
    Point p(3, 5);              // constructor chạy trước
    cout << "Trong main" << endl;
    return 0;                   // kết thúc main → destructor chạy sau
}
▸ KẾT QUẢ 
Tạo Point (3, 5)
Trong main
Đã hủy Point (3, 5)

Vậy chính xác destructor chạy lúc nào? Hãy xem object nằm trong một khối { } nhỏ — nó "ra đi" ngay khi khối đó kết thúc, chứ không đợi hết chương trình:

phamvi.cpp 
#include <iostream>
using namespace std;

class Point {
public:
    int x, y;

    Point(int a, int b) {
        x = a; y = b;
        cout << "Tạo Point (" << x << ", " << y << ")" << endl;
    }
    ~Point() {
        cout << "Đã hủy Point (" << x << ", " << y << ")" << endl;
    }
};

int main() {
    Point p(1, 2);
    {
        Point q(7, 8);          // object trong block nhỏ
        cout << "Trong block" << endl;
    }                           // q hết phạm vi → destructor chạy NGAY
    cout << "Ket thuc main" << endl;
    return 0;
}
▸ KẾT QUẢ 
Tạo Point (1, 2)
Tạo Point (7, 8)
Trong block
Đã hủy Point (7, 8)
Ket thuc main
Đã hủy Point (1, 2)
// CẢNH BÁO

Ba điều dễ hiểu nhầm về destructor: (1) nó chạy khi object hết phạm vi — ra khỏi khối { } gần nhất hoặc khi hàm chứa nó kết thúc; (2) nếu nhiều object cùng hết phạm vi, thứ tự hủy là ngược với thứ tự tạo (tạo sau hủy trước); (3) object cấp phát bằng new không tự hủy khi hết phạm vi — phải gọi delete, nếu không destructor không bao giờ chạy.

TỔNG KẾT BÀI 14

  • Constructor cùng tên class, không kiểu trả về, tự chạy ngay khi object được tạo.
  • Constructor nhận tham số để nạp dữ liệu ban đầu: Point p(3, 5); — có thể viết nhiều constructor khác bộ tham số.
  • Không viết constructor nào thì C++ tự sinh constructor mặc định rỗng — thuộc tính chứa giá trị rác.
  • Destructor có dạng ~Point(), không tham số, không kiểu trả về, tự chạy khi object hết phạm vi.
  • Object trong khối { } bị hủy ngay khi ra khỏi khối; nhiều object thì hủy theo thứ tự ngược lúc tạo.
  • Object cấp phát bằng new phải delete thủ công, destructor mới chạy.
