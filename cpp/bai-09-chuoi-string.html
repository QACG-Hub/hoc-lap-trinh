Chuỗi: string & char

[ NHIỆM VỤ #09 ] Chương 3 — Hàm & mảng Mức độ: Chiến binh

Chương trình đẹp là chương trình biết nói — và để nói, nó cần chuỗi. Trong C++ có hai "sinh vật" hay bị nhầm lẫn: char (một ký tự) và string (cả đoạn văn). Nhiệm vụ hôm nay: thuần phục cả hai, nối chuỗi, so sánh chuỗi, đọc cả dòng có dấu cách và nghịch với length(), substr(), find(). ⚡

string & char

Để dùng string, bạn cần nạp thêm thư viện #include <string> (ngoài iostream). Chuỗi trong C++ nối bằng dấu + và so sánh bằng == — giống hệt Python, chỉ khác là không quên dấu chấm phẩy:

chuoi.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ten = "Neo";
    string ho = "Tran";
    string full = ho + " " + ten;    // nối chuỗi bằng +
    cout << full << endl;
    cout << (ten == "Neo") << endl;  // so sánh bằng == (1 = đúng)
    return 0;
}

Còn đây là cặp đôi dễ gây nhầm nhất trong C++: char và string. Nhìn thì giống nhau khi in, nhưng bản chất khác hẳn:

char-vs-string.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    char kyTu = 'A';          // nháy ĐƠN: đúng 1 ký tự
    string chuoi = "A";       // nháy KÉP: chuỗi (có thể dài bao nhiêu cũng được)
    cout << kyTu << endl;
    cout << chuoi << endl;
    cout << chuoi.length() << endl;  // chuỗi "A" có 1 ký tự
    return 0;
}

Đừng tráo dấu nháy! char c = "A"; là lỗi biên dịch (chuỗi nháy kép không nhét vừa một char), còn string s = 'A'; cũng lỗi (nháy đơn là ký tự, không phải chuỗi). Quy tắc nhớ nhanh: ĐƠN = 1 ký tự (char), KÉP = chuỗi (string).

Nhập chuỗi & thao tác

Muốn người dùng nhập cả câu "Neo Tran" (có dấu cách), đừng dùng cin >> — hãy dùng getline(cin, ten). Nó đọc trọn một dòng cho tới khi gặp phím Enter:

getline.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string ten;
    cout << "Nhap ten: ";
    getline(cin, ten);          // đọc CẢ dòng, kể cả dấu cách
    cout << "Chao " << ten << "!" << endl;
    return 0;
}
▸ KẾT QUẢ 
Nhap ten: Neo Tran
Chao Neo Tran!

Chú thích nhỏ: đoạn Neo Tran là bạn gõ vào; phần chữ còn lại là chương trình in ra. Nếu dùng cin >> ten, biến ten chỉ nhận được mỗi chữ Neo — phần sau dấu cách bị bỏ rơi.

Ba "vũ khí" của string

Chuỗi trong C++ là một đối tượng có sẵn nhiều hàm hữu ích. Ba hàm dùng nhiều nhất: length() (đếm ký tự), substr(vị_trí, số_ký_tự) (cắt chuỗi con), find("...") (tìm vị trí xuất hiện). Và tất nhiên, bạn có thể duyệt từng ký tự bằng vòng for:

thao-tac.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "Hoc C++";
    cout << s.length() << endl;     // 7 ký tự
    cout << s.substr(0, 3) << endl; // lấy 3 ký tự từ vị trí 0
    cout << s.find("C++") << endl;  // vị trí đầu tiên tìm thấy

    int dem = 0;
    for (int i = 0; i < s.length(); i++)
        if (s[i] == '+') dem++;     // duyệt từng ký tự
    cout << "So dau +: " << dem << endl;
    return 0;
}

TỔNG KẾT BÀI 09

  • char là MỘT ký tự, giá trị trong nháy ĐƠN: 'A'; string là chuỗi, giá trị trong nháy KÉP: "A".
  • Dùng string cần #include <string> (ngoài iostream).
  • Nối chuỗi bằng +: "Tran" + " " + "Neo"; so sánh bằng == (không phải =).
  • cin >> ten chỉ đọc tới dấu cách; muốn đọc cả dòng dùng getline(cin, ten).
  • Thao tác quen dùng: s.length(), s.substr(vị_trí, số_ký_tự), s.find("...").
  • Có thể duyệt từng ký tự bằng vòng for: s[i] là ký tự thứ i, và so sánh với char như s[i] == '+'.
