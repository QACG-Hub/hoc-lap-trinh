Biến trong C++

Trong Python, bạn chỉ cần gõ tuoi = 20 là xong. Còn C++ bắt buộc ghi rõ kiểu ngay khi khai báo: muốn chiếc hộp đựng số nguyên thì phải mở đầu bằng int, đựng số thực thì bằng double… Chính quy tắc này giúp C++ nhanh và chặt chẽ hơn.

bien.cpp 
#include <iostream>
using namespace std;

int main() {
    int tuoi = 20;              // khai báo kèm kiểu int
    cout << tuoi << endl;       // in ra 20

    tuoi = 21;                  // gán lại giá trị mới — được!
    cout << tuoi << endl;       // in ra 21

    const double PI = 3.14;     // hằng số — gán lại sẽ bị lỗi
    cout << PI << endl;         // in ra 3.14
    return 0;
}
▸ KẾT QUẢ 
20
21
3.14

Hai điều cần nhớ: biến thường gán lại được thoải mái, còn const tạo hằng số — gán lại sẽ báo lỗi biên dịch ngay. Giờ giải phẫu dòng khai báo:

Các kiểu dữ liệu cơ bản

C++ cho bạn một bộ kiểu "đóng hộp" sẵn — chỉ cần chọn đúng hộp cho dữ liệu. Đây là những kiểu bạn sẽ dùng hằng ngày:

KiểuLưu gìVí dụGhi chú
intsố nguyên20, -7dùng nhiều nhất
doublesố thực (chính xác gấp đôi float)8.5, 3.14mặc định nên chọn cho số thực
floatsố thực (độ chính xác thấp hơn)3.14fít dùng hơn double
charMỘT ký tự — nháy ĐƠN'A', '7'nháy đơn mới là ký tự
boolđúng / saitrue, falseviết thường; in ra thành 1/0
stringchuỗi ký tự — nháy KÉP"An", "Xin chào"cần #include <string>

Xem đủ bộ kiểu trong một chương trình hoàn chỉnh:

kieu-du-lieu.cpp 
#include <iostream>
#include <string>
using namespace std;

int main() {
    int tuoi = 20;              // số nguyên
    double diem = 8.5;          // số thực
    char xepLoai = 'A';         // một ký tự — nháy ĐƠN
    bool totNghiep = true;      // đúng / sai
    string ten = "An";          // chuỗi — nháy KÉP

    cout << ten << " - " << tuoi << " tuổi" << endl;
    cout << "Điểm: " << diem << " - Xếp loại: " << xepLoai << endl;
    cout << "Tốt nghiệp: " << totNghiep << endl;   // bool in ra 1/0
    return 0;
}

Ép kiểu & xem trước cin

Chìa khoá để 7 / 2 ra 3.5 là ép kiểu (type casting) — nói với compiler: "hãy tính phép này như số thực đi". Chỉ cần ép một trong hai toán hạng thành double là cả phép chia chuyển sang số thực:

ep-kieu.cpp 
#include <iostream>
using namespace std;

int main() {
    cout << 7 / 2 << endl;                        // chia hai int → 3
    cout << (double)7 / 2 << endl;                // ép kiểu "kiểu C" → 3.5
    cout << static_cast<double>(7) / 2 << endl;   // ép kiểu hiện đại → 3.5

    int x = 3.9;                                  // gán số thực vào int...
    cout << x << endl;                            // ...bị cắt thành 3
    return 0;
}
▸ KẾT QUẢ 
3
3.5
3.5
3
// GHI NHỚ

Cách ép kiểu C (double)7 vẫn chạy tốt, nhưng C++ hiện đại khuyến nghị static_cast<double>(7) — rõ ràng hơn và ít gây lỗi ngầm. Đi thi đấu thuật toán bạn sẽ gặp cả hai.

// CẢNH BÁO

Gán số thực vào biến int không làm tròn mà cắt thẳng phần thập phân: int x = 3.9; cho x bằng 3 (không phải 4). Hãy chọn kiểu đúng ngay từ lúc khai báo!

Xem trước: đọc dữ liệu với cin

Nếu cout đẩy dữ liệu ra màn hình với <<, thì cin kéo dữ liệu người dùng gõ vào biến với >>. Chương trình đầu tiên có tương tác trông như thế này — bạn sẽ học kỹ ở bài sau:

nhap.cpp 
#include <iostream>
using namespace std;

int main() {
    int tuoi;
    cout << "Nhập tuổi của bạn: ";
    cin >> tuoi;
    cout << "Bạn " << tuoi << " tuổi!" << endl;
    return 0;
}
▸ KẾT QUẢ 
Nhập tuổi của bạn: 20
Bạn 20 tuổi!

TỔNG KẾT BÀI 03

  • Khai báo biến trong C++ bắt buộc ghi kiểu: int tuoi = 20; — khác Python (kiểu động).
  • Biến thường gán lại được; const tạo hằng số, gán lại sẽ lỗi biên dịch.
  • Kiểu cơ bản: int (số nguyên), double/float (số thực), char (một ký tự, nháy đơn), bool (true/false, in ra 1/0), string (chuỗi, nháy kép, cần #include <string>).
  • Chia hai số nguyên là chia nguyên: 7 / 2 ra 3; muốn 3.5 phải ép kiểu (double)7 / 2 hoặc static_cast<double>(7) / 2.
  • Gán số thực vào int sẽ cắt phần thập phân (int x = 3.9; → 3).
  • Xem trước: cin >> bien; đọc dữ liệu người dùng nhập từ bàn phím — học kỹ ở bài sau.
