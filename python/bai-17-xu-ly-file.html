Chương trình chỉ chạy rồi… quên sạch kết quả khi tắt máy thì thật uổng. Nhiệm vụ hôm nay: dạy chương trình ghi kết quả xuống file để lưu giữ, và đọc file để tiếp tục xử lý. Nhờ vậy, dữ liệu của bạn "bất tử" qua mọi lần tắt máy! ⚡

Ghi file

Muốn làm việc với file, bạn mở nó ra bằng hàm open(đường_dẫn, mode, encoding=...). Mode "w" nghĩa là "ghi mới" — nếu file đã tồn tại, nội dung cũ bị xóa sạch để ghi lại từ đầu. Ghi xong thì đóng file bằng f.close().

ghi-file.py 
f = open("data.txt", "w", encoding="utf-8")
f.write("Xin chào\n")
f.write("Dòng thứ hai")
f.close()
print("Đã ghi xong!")
▸ KẾT QUẢ 
Đã ghi xong!

Sau khi chạy, file data.txt nằm cạnh chương trình, chứa đúng hai dòng: Xin chào và Dòng thứ hai. Cùng giải phẫu lời gọi open(...) để hiểu từng tham số:

Trên Windows, quên encoding="utf-8" là công thức lỗi tiếng Việt: chữ Xin chào có thể bị lưu sai hoặc gây UnicodeEncodeError. Cứ thêm encoding="utf-8" ngay từ đầu cho chắc — thói quen của cao thủ!

Đọc file

Đọc file cũng qua open(...) nhưng mode là "r". Sau khi có đối tượng file, bạn có hai món vũ khí chính: read() — đọc cả file thành một chuỗi dài; readlines() — đọc thành danh sách các dòng (list). Xong việc nhớ f.close().

doc-file.py 
f = open("data.txt", "r", encoding="utf-8")
noi_dung = f.read()
f.close()
print(noi_dung)
▸ KẾT QUẢ 
Xin chào
Dòng thứ hai
doc-tung-dong.py 
f = open("data.txt", "r", encoding="utf-8")
cac_dong = f.readlines()
f.close()
print(cac_dong)
▸ KẾT QUẢ 
['Xin chào\n', 'Dòng thứ hai']
// GHI NHỚ

So sánh kết quả hai lần đọc: read() trả về một chuỗi gộp cả file; readlines() trả về một list các dòng. Để ý mỗi phần tử giữ luôn ký tự xuống dòng \n ở cuối (trừ dòng cuối cùng không có) — đó là lý do thấy cả \n trong list!

with — tự đóng file

Gõ f.close() hoài cũng mỏi tay — quên một lần là rò rỉ tài nguyên ngay. Python có chiêu cao thủ: khối with open(...) as f:. Hết khối, file được tự động đóng giúp bạn, khỏi lo quên!

ghi-bang-with.py 
with open("ghi-chu.txt", "w", encoding="utf-8") as f:
    f.write("Học Python mỗi ngày\n")

print("Xong, file tự đóng rồi!")
▸ KẾT QUẢ 
Xong, file tự đóng rồi!

Còn đây là combo "đọc từng dòng": dùng for dong in f để duyệt file như duyệt danh sách — mỗi vòng lặp nhận một dòng. Thử đếm xem file data.txt có bao nhiêu dòng:

dem-dong.py 
with open("data.txt", "r", encoding="utf-8") as f:
    dem = 0
    for dong in f:
        dem = dem + 1

print("Số dòng:", dem)
▸ KẾT QUẢ 
Số dòng: 2
// CẢNH BÁO

with đóng file kể cả khi có lỗi xảy ra bên trong khối — dữ liệu vẫn an toàn. Ngược lại, cách mở file thường mà quên f.close() khi gặp lỗi có thể khiến file bị khóa hoặc mất dữ liệu chưa ghi. Từ giờ, "mở file là dùng with" — quy tắc vàng!

TỔNG KẾT BÀI 17

  • open("data.txt", "w", encoding="utf-8") mở file để ghi — nội dung cũ bị xóa; ghi bằng f.write(...).
  • f.close() đóng file sau khi dùng; luôn nhớ encoding="utf-8" cho tiếng Việt.
  • Mode "r" để đọc: read() trả cả nội dung thành chuỗi, readlines() trả list các dòng.
  • with open(...) as f: tự đóng file khi hết khối — kể cả khi có lỗi.
  • Duyệt file từng dòng bằng for dong in f: — đếm dòng, lọc dữ liệu, xử lý tuỳ thích.
