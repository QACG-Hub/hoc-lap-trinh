Kế thừa

Kế thừa (inheritance) cho phép một class thừa hưởng trọn vẹn thuộc tính và phương thức của class khác. Class được thừa hưởng gọi là lớp cha (lớp cơ sở); class đi thừa hưởng gọi là lớp con. Cú pháp chỉ thêm tên lớp cha vào trong ngoặc: class Dog(Animal):.

animal-dog.py 
class Animal:
    def __init__(self, ten, tuoi):
        self.ten = ten
        self.tuoi = tuoi

    def gioi_thieu(self):
        print("Tôi là", self.ten, "và", self.tuoi, "tuổi")

class Dog(Animal):
    def sua(self):
        print(self.ten, "nói: Gâu gâu!")

d = Dog("Milu", 2)
d.gioi_thieu()
d.sua()
▸ KẾT QUẢ 
Tôi là Milu và 2 tuổi
Milu nói: Gâu gâu!

Để ý: class Dog không hề viết __init__ hay gioi_thieu(), nhưng Dog("Milu", 2) vẫn chạy trơn tru — nó dùng lại nguyên bản của cha. Giải phẫu dòng kế thừa:

Quan hệ kế thừa đọc là "là một": Dog là một Animal. Lớp con hưởng tất cả thuộc tính lẫn phương thức của cha (kể cả __init__), rồi có thể thêm phương thức riêng như sua().

super() & ghi đè

Lớp con có thể ghi đè (override): định nghĩa lại một phương thức cùng tên với lớp cha để thay hành vi cũ. Nhưng thường lớp con vẫn muốn cha lo phần dữ liệu chung — lúc đó gọi super().__init__(...) để chạy __init__ của cha trước, rồi mới thêm phần riêng.

goi-cha.py 
class Animal:
    def __init__(self, ten):
        self.ten = ten

class Dog(Animal):
    def __init__(self, ten):
        super().__init__(ten)      # cha lo phần self.ten
        self.loai = "Chó"          # con thêm phần riêng

d = Dog("Milu")
print(d.ten, "-", d.loai)

Ghi đè phương thức cũng tương tự: lớp con viết lại speak(). Nếu muốn chạy cả phiên bản của cha rồi mới thêm phần mới, gọi super().speak() ngay trong phương thức ghi đè:

ghi-de.py 
class Animal:
    def speak(self):
        print("... một âm thanh chung chung")

class Dog(Animal):
    def speak(self):
        super().speak()            # chạy bản gốc của cha
        print("Gâu gâu!")          # rồi thêm phần của con

d = Dog()
d.speak()
▸ KẾT QUẢ 
... một âm thanh chung chung
Gâu gâu!
// CẢNH BÁO

Nếu lớp con tự viết __init__ mà quên super().__init__(...), thuộc tính của cha sẽ không bao giờ được tạo. Truy cập d.ten lúc đó sẽ báo AttributeError: 'Dog' object has no attribute 'ten'. Viết __init__ ở con thì nhớ gọi cha!

Đa hình

Đa hình (polymorphism — "nhiều hình dạng") là hệ quả đẹp nhất của kế thừa: cho các object thuộc nhiều lớp khác nhau vào cùng một list, rồi dùng một vòng for gọi cùng một phương thức con.speak(). Mỗi object tự chạy theo cách của lớp nó!

da-hinh.py 
class Animal:
    def speak(self):
        print("...")

class Dog(Animal):
    def speak(self):
        print("Gâu gâu!")

class Cat(Animal):
    def speak(self):
        print("Meo meo!")

for con in [Dog(), Cat()]:
    con.speak()
▸ KẾT QUẢ 
Gâu gâu!
Meo meo!

Đa hình chỉ cần một điều kiện: các lớp con ghi đè cùng tên phương thức. Nhờ vậy code gọi không cần biết object thuộc lớp nào — bạn thêm lớp mới cả chục năm sau, vòng for cũ vẫn chạy đúng.
