Dữ liệu thật ngoài đời phần lớn là… chuỗi: tên người, địa chỉ, tin nhắn, dữ liệu nhập từ bàn phím. Nhiệm vụ cuối của chương này là biến bạn thành cao thủ chuỗi: cắt, ghép, làm sạch và định dạng mọi chuỗi bằng những chiêu gọn gàng nhất. ⚡

Truy cập & cắt chuỗi

Chuỗi hoạt động gần giống list: mỗi ký tự có một index bắt đầu từ 0, và bạn cắt được một đoạn bằng slice s[a:b] — lấy từ index a đến trước index b.

cat-chuoi.py 
s = "Python"
print(s[0])      # ký tự đầu tiên
print(s[-1])     # ký tự cuối cùng
print(len(s))    # độ dài chuỗi
print(s[0:3])    # 3 ký tự đầu
print(s[2:])     # từ index 2 đến hết
print(s[::-1])   # đảo ngược chuỗi!

Phương thức chuỗi

Chuỗi có sẵn bộ phương thức (method) đủ để làm sạch và biến đổi dữ liệu: strip() cắt khoảng trắng thừa, upper()/lower() đổi hoa thường, replace() thay thế, split() tách thành list, join() nối list thành chuỗi, find() tìm vị trí.

phuong-thuc-chuoi.py 
s = "  Học Python  "
print(s.strip())                        # bỏ khoảng trắng hai đầu
print(s.strip().upper())                # làm sạch rồi IN HOA
print("PYTHON".lower())                 # chuỗi thường
print("python".replace("p", "P"))       # thay thế
print("a,b,c".split(","))               # tách thành list
print("-".join(["2026", "10", "17"]))   # nối list thành chuỗi
print("Học Python".find("Python"))      # tìm vị trí

Các phương thức chuỗi không sửa chuỗi gốc — chúng trả về chuỗi mới. Muốn giữ kết quả, hãy gán lại: s = s.strip().upper(). Cũng vì thế bạn nối được liên hoàn: s.strip().upper().

f-string — in chuỗi không còn đau đầu

Trước đây muốn ghép biến vào chuỗi bạn phải dùng dấu + lích kích. f-string giải quyết tất cả: thêm chữ f trước dấu nháy, rồi đặt biến hoặc biểu thức trong cặp ngoặc nhọn { } — Python tự thay giá trị vào. Kèm luôn khả năng định dạng số như :.2f (2 chữ số thập phân).

f-string.py 
ten = "An"
diem = 8.5

print(f"Xin chào {ten}!")
print(f"{ten} được {diem} điểm")
print(f"Điểm làm tròn: {diem:.2f}")

don_gia = 12000
so_luong = 3
print(f"Tổng tiền: {don_gia * so_luong:,} VNĐ")
