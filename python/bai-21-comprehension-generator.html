Comprehension & generator

Bạn đã quen cảnh: tạo list rỗng, viết vòng for, rồi append từng phần tử — ba dòng chỉ để làm một việc. List comprehension

List comprehension là cách tạo list ngay trong một dòng, theo mẫu: [biểu_thức for x in dãy] — Python duyệt dãy, tính biểu thức cho từng x và gom kết quả vào list. Có thể thêm bộ lọc if để chỉ giữ những phần tử thoả điều kiện.

cach-cu-cach-moi.py 
# Cách cũ — 4 dòng
so = []
for x in range(5):
    so.append(x * 2)
print(so)

# Cách mới — 1 dòng, cùng kết quả
so2 = [x * 2 for x in range(5)]
print(so2)
▸ KẾT QUẢ 
[0, 2, 4, 6, 8]
[0, 2, 4, 6, 8]
loc-va-bien-doi.py 
# Thêm bộ lọc if: chỉ giữ số chẵn
chan = [x for x in range(10) if x % 2 == 0]
print(chan)

# Biến đổi ngay trong biểu thức
print([x ** 2 for x in range(1, 5)])
▸ KẾT QUẢ 
[0, 2, 4, 6, 8]
[1, 4, 9, 16]

Dict/Set comprehension & generator

Đổi cặp ngoặc là đổi "sản phẩm": ngoặc nhọn { } với cặp key: value tạo ra dict comprehension; { } chỉ có một biểu thức tạo ra set. Còn nếu dùng ngoặc tròn ( ) thì bạn được một generator expression — nó không tạo list ngay mà sinh từng giá trị khi được hỏi, rất hợp để đưa thẳng vào sum().

dict-set-generator.py 
binh_phuong = {x: x ** 2 for x in range(5)}
print(binh_phuong)

tap = {x % 3 for x in range(7)}
print(tap)

tong = sum(x * x for x in range(5))
print(tong)
▸ KẾT QUẢ 
{0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
{0, 1, 2}
30

Còn generator "chính chủ" là một hàm dùng từ khóa yield thay cho return. Mỗi lần chương trình cần giá trị tiếp theo, hàm chạy tới yield, nhả một giá trị rồi tạm dừng — lần sau chạy tiếp đúng chỗ đó:

dem-len.py 
def dem_len(n):
    for i in range(1, n + 1):
        yield i

for x in dem_len(3):
    print(x)
▸ KẾT QUẢ 
1
2
3
// CẢNH BÁO

Generator chỉ chạy được MỘT lần. Nó như tuýp kem đánh răng: bóp hết là hết, không nhồi lại được! Xem điều gì xảy ra khi gọi sum() hai lần trên cùng một generator:

mot-lan-thoi.py 
g = (x * x for x in range(3))
print(sum(g))    # lần đầu: 0 + 1 + 4
print(sum(g))    # lần hai: generator đã cạn!
▸ KẾT QUẢ 
5
0
// GHI NHỚ

Muốn dùng lại dữ liệu của generator, hãy "đổ" nó vào list một lần: ds = list(g), rồi thoải mái duyệt ds bao nhiêu lần cũng được.

TỔNG KẾT BÀI 21

  • List comprehension: [biểu_thức for x in dãy] — thay cả vòng for + append bằng một dòng.
  • Thêm bộ lọc: [x for x in range(10) if x % 2 == 0] — if đặt sau phần for.
  • Dict comprehension: {x: x ** 2 for x in range(5)}; set comprehension: {x % 3 for x in range(7)}.
  • Generator expression (x * x for x in range(5)) sinh giá trị khi cần — dùng gọn trong sum().
  • yield biến hàm thành generator: nhả từng giá trị rồi tạm dừng, chạy tiếp khi được hỏi.
  • Generator chỉ chạy một lần — muốn dùng lại thì list(g) trước.
