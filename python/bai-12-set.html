Set — tập hợp không trùng

Set (tập hợp) là một nhóm giá trị không trùng nhau, viết trong cặp ngoặc nhọn { } — ví dụ {1, 2, 3}. Đặc điểm "ăn tiền": nếu bạn đưa vào dữ liệu có giá trị lặp, set tự động loại trùng.

loc-trung.py 
ds = [1, 2, 2, 3, 3, 3]
st = set(ds)         # tự loại trùng ngay lập tức
print(st)

st.add(4)            # thêm phần tử
st.remove(1)         # xóa phần tử
print(st)
print(len(st))       # đếm số phần tử
▸ KẾT QUẢ 
{1, 2, 3}
{2, 3, 4}
3

Set không đánh index — viết st[0] sẽ báo lỗi TypeError: 'set' object is not subscriptable. Muốn kiểm tra một giá trị có trong set không, dùng 2 in st (trả về True/False).

// GHI NHỚ

Set không có thứ tự cố định — đừng bao giờ tin vào thứ tự hiển thị của nó. Muốn xem gọn theo thứ tự tăng dần, dùng sorted(st).

Phép toán tập hợp

Set hỗ trợ đúng các phép toán bạn từng học ở môn Toán: hợp (| hoặc union()), giao (& hoặc intersection()), hiệu (- hoặc difference()). Cực hợp khi bạn phải so sánh hai nhóm dữ liệu.

phep-toan-set.py 
a = {1, 2, 3, 4}
b = {3, 4, 5}

print(a | b)                # hợp — có trong a HOẶC b
print(a & b)                # giao — có trong CẢ HAI
print(a - b)                # hiệu — có trong a nhưng KHÔNG có trong b

print(a.union(b))           # tên đầy đủ của |
print(a.intersection(b))    # tên đầy đủ của &
print(a.difference(b))      # tên đầy đủ của -
▸ KẾT QUẢ 
{1, 2, 3, 4, 5}
{3, 4}
{1, 2}
{1, 2, 3, 4, 5}
{3, 4}
{1, 2}
// GHI NHỚ

Ba phép tốc ký và ba phương thức là một cặp bài trùng: a | b = a.union(b), a & b = a.intersection(b), a - b = a.difference(b).

TỔNG KẾT BÀI 12

  • Set viết trong ngoặc nhọn {1, 2, 3} — các phần tử không trùng nhau.
  • Lọc trùng từ list cực nhanh: set(ds).
  • Thêm/xóa: st.add(4), st.remove(1); kiểm tra thành viên: 2 in st.
  • Set không đánh index, không có thứ tự cố định.
  • Phép toán: | hợp, & giao, - hiệu (hoặc union/intersection/difference).
