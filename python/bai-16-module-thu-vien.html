Module & thư viện chuẩn

[ NHIỆM VỤ #16 ] Chương 4 — Hàm & module Mức độ: Chiến binh

Bạn không cần tự viết mọi thứ từ đầu — Python đi kèm cả một kho vũ khí khổng lồ gọi là thư viện chuẩn (standard library): tính căn bậc hai, tung xúc xắc ngẫu nhiên, lấy ngày tháng… tất cả đã có sẵn, chỉ chờ bạn import về dùng. Nhiệm vụ hôm nay: học cách "triệu hồi" chúng! ⚡

import — dùng code có sẵn

Module là một file chứa sẵn các hàm và hằng số. Muốn dùng, bạn viết import tên_module, rồi gọi hàm qua dấu chấm: tên_module.tên_hàm(...).

can-bac-hai.py 
import math

print(math.sqrt(16))
print(math.sqrt(2))
▸ KẾT QUẢ 
4.0
1.4142135623730951

Nếu chỉ cần một vài thứ, bạn có thể lấy thẳng bằng from … import … và gọi không cần tiền tố. Còn khi tên module dài dòng, đặt bí danh bằng as cho gọn:

lay-truc-tiep.py 
from math import pi

print(pi)
▸ KẾT QUẢ 
3.141592653589793
bi-danh.py 
import math as m

print(m.sqrt(25))
▸ KẾT QUẢ 
5.0
// GHI NHỚ

Ba kiểu import bạn vừa gặp: import math → gọi math.sqrt(...); from math import pi → gọi thẳng pi; import math as m → gọi m.sqrt(...). Chọn kiểu nào cũng đúng, miễn bạn nhớ cách gọi!

// CẢNH BÁO

Đừng đặt tên file của bạn trùng tên module — ví dụ math.py. Khi đó import math có thể "vơ" nhầm file của bạn thay vì thư viện chuẩn, gây lỗi khó hiểu như AttributeError: module 'math' has no attribute 'sqrt'. Đặt tên file kiểu toan-hoc.py cho an toàn!

Thư viện chuẩn hay dùng

Thư viện chuẩn có hàng trăm module — nhưng ba "cạ cứng" dưới đây sẽ theo bạn suốt chặng đường: math (toán học), random (ngẫu nhiên) và datetime (ngày tháng).

math — toán học

math.sqrt(x) tính căn bậc hai, math.pi là hằng số π nổi tiếng:

toan-hoc.py 
import math

print(math.sqrt(81))
print(math.pi)
▸ KẾT QUẢ 
9.0
3.141592653589793

random — ngẫu nhiên

random.randint(a, b) trả về số nguyên ngẫu nhiên từ a đến b (bao gồm cả hai đầu), còn random.choice(ds) chọn ngẫu nhiên một phần tử của danh sách:

xuc-xac.py 
import random

print(random.randint(1, 6))
print(random.choice(["An", "Bình", "Cường"]))
▸ KẾT QUẢ 
6
An

Kết quả trên là một lần chạy cụ thể — mỗi lần chạy lại, con xúc xắc và cái tên có thể khác. Đó chính là điều thú vị của random!

datetime — ngày tháng

date.today() cho biết ngày hôm nay, còn date(nam, thang, ngay) tạo một ngày bất kỳ để tính toán:

ngay-thang.py 
from datetime import date

hom_nay = date.today()
print("Hôm nay:", hom_nay)
sinh_nhat = date(2010, 5, 20)
print("Sinh nhật:", sinh_nhat)
▸ KẾT QUẢ 
Hôm nay: 2026-10-17
Sinh nhật: 2010-05-20
// GHI NHỚ

Dòng Hôm nay: 2026-10-17 là ngày tác giả chạy thử — máy bạn chạy hôm nào sẽ in ngày hôm đó. Còn sinh_nhat.year, sinh_nhat.month cho bạn lấy riêng từng phần của một ngày.

  • Không đặt file trùng tên module (math.py) kẻo import nhầm file của bạn.
  • math: sqrt, pi — random: randint, choice — datetime: date.today().
