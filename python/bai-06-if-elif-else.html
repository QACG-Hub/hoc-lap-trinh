Rẽ nhánh if / elif / else

[ NHIỆM VỤ #06 ] Chương 2 — Cấu trúc điều khiển Mức độ: Chiến binh

Từ hôm nay chương trình của bạn biết suy nghĩ: đủ điểm thì báo "Đậu", trời mưa thì nhắc mang áo, số âm thì xử lý khác số dương. Công cụ để ra quyết định là if (nếu), elif (ngược lại nếu) và else (còn lại). Chương 2 chính thức bắt đầu — vào việc thôi! ⚡

if — ra quyết định

if kiểm tra một điều kiện: nếu điều kiện đúng (True) thì chạy khối lệnh bên trong, nếu sai (False) thì bỏ qua toàn bộ khối lệnh đó.

dau-hay-rot.py 
diem = 6
if diem >= 5:
    print("Đậu rồi!")
▸ KẾT QUẢ 
Đậu rồi!

Còn khi điều kiện sai, khối lệnh bên trong bị bỏ qua "không thương tiếc":

rot.py 
diem = 4
if diem >= 5:
    print("Đậu rồi!")
print("Chương trình kết thúc")

Chương trình kết thúc

Hai lỗi "cửa miệng" của người mới học: quên dấu : → SyntaxError; thụt lề lệch cột (khi 2 dấu cách, khi 4 dấu cách) → IndentationError. Python cực kỳ khắt khe chuyện thụt lề — hãy luôn dùng 4 dấu cách cho mỗi tầng.

else & elif

if chỉ lo một trường hợp. Muốn xử lý nhiều mức, ta thêm elif ("ngược lại nếu") cho các mức giữa, và else ("còn lại") để hứng mọi trường hợp chưa khớp. Python kiểm tra từ trên xuống và chỉ chạy nhánh đúng đầu tiên.

xep-loai.py 
diem = 7.5
if diem >= 8:
    print("Giỏi")
elif diem >= 6.5:
    print("Khá")
else:
    print("Cần cố gắng")
▸ KẾT QUẢ 
Khá

Với diem = 7.5: điều kiện đầu diem >= 8 sai, Python nhảy xuống elif diem >= 6.5 thấy đúng → chạy print("Khá") rồi thoát khỏi cả chuỗi, không xét tới else nữa.

// GHI NHỚ

Trong một chuỗi if/elif/else, chỉ duy nhất một nhánh được chạy. else là nhánh "hứng hết" — không kèm điều kiện, và nếu có thì nó luôn đứng cuối cùng.

Điều kiện nâng cao

Điều kiện trong if có thể là biểu thức logic ghép từ nhiều vế bằng and/or — sức mạnh của bài 05 phát huy tác dụng! Ví dụ kinh điển: kiểm tra tuổi thiếu niên (13–19).

thieu-nien.py 
tuoi = 16
if tuoi >= 13 and tuoi <= 19:
    print("Bạn là thiếu niên")
else:
    print("Không phải thiếu niên")
▸ KẾT QUẢ 
Bạn là thiếu niên

Một if còn có thể chứa if khác ở bên trong (if lồng nhau) để kiểm tra từng tầng điều kiện:

long-if.py 
diem = 9
if diem >= 5:
    if diem >= 8:
        print("Giỏi")
    else:
        print("Đạt")
else:
    print("Chưa đạt")
▸ KẾT QUẢ 
Giỏi
// GHI NHỚ

Mỗi tầng lồng nhau thêm 4 dấu cách thụt lề. If lồng nhau rất mạnh nhưng dễ rối — nếu lồng quá 3 tầng, hãy nghĩ cách viết lại bằng and/or cho gọn.
