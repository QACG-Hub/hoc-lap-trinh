Python là gì?

Python là một ngôn ngữ lập trình ra đời năm 1991, do Guido van Rossum tạo ra. Cái tên này lấy từ nhóm hài kịch ông yêu thích, chứ không phải loài trăn. Điểm khiến Python nổi tiếng khắp thế giới: cú pháp dễ đọc, gần với tiếng Anh — người mới học tập trung vào tư duy lập trình thay vì đánh vật với ký hiệu rối rắm.

Python có mặt ở gần như mọi lĩnh vực:

  • Làm web — xây website, API với Django, Flask.
  • Trí tuệ nhân tạo (AI) — chatbot, nhận dạng ảnh, học máy với PyTorch, TensorFlow.
  • Tự động hóa — viết script đổi tên hàng trăm file, gửi email, thu thập dữ liệu... thay việc làm tay.
  • Khoa học dữ liệu — phân tích số liệu, vẽ biểu đồ với pandas, matplotlib.

Python là ngôn ngữ THÔNG DỊCH

Ngôn ngữ lập trình chia làm hai nhóm. Nhóm biên dịch như C++ phải dịch toàn bộ code thành mã máy trước khi chương trình chạy được — bạn sẽ học kỹ bước này ở lộ trình C++. Còn Python thuộc nhóm thông dịch (interpreted): trình thông dịch đọc và chạy từng dòng lệnh một, gặp dòng nào xử lý dòng đó, không cần bước biên dịch riêng.

Nghĩa là bạn gõ code, chạy và có kết quả ngay lập tức:

diem.py 
# Cú pháp đọc là hiểu ngay
toan = 8
van = 9
print("Điểm trung bình:", (toan + van) / 2)
▸ KẾT QUẢ 
Điểm trung bình: 8.5
chao.py 
ten = "An"
print("Chào", ten, "— chúc học Python vui!")
▸ KẾT QUẢ 
Chào An — chúc học Python vui!
// GHI NHỚ

Vì chạy từng dòng, Python dừng ngay tại dòng gây lỗi và chỉ rõ số dòng đó — tìm và sửa lỗi rất nhanh. Ưu điểm của Python là học nhanh, viết nhanh; còn tốc độ tối đa là sân chơi của C++.

Cài đặt Python

Bản Python chính thức được tải miễn phí tại python.org/downloads. Cách cài đặt khác nhau đôi chút giữa các hệ điều hành:

  • Windows — tải file cài đặt (.exe), mở lên và tick "Add Python to PATH" ở màn hình đầu tiên, rồi bấm "Install Now".
  • macOS — Python 3 thường có sẵn; máy nào chưa có thì tải bản cài đặt từ python.org.
  • Linux (Ubuntu, Fedora...) — hầu như máy nào cũng có sẵn python3, không cần cài thêm.
// CẢNH BÁO

Trên Windows, nếu quên tick "Add Python to PATH", terminal sẽ không nhận ra lệnh python và bạn phải cài lại từ đầu. Hãy tick trước khi bấm Install!

Kiểm tra xem máy đã có Python chưa bằng lệnh sau trong terminal:

terminal 
python3 --version
▸ KẾT QUẢ 
Python 3.12.4
// GHI NHỚ

Trên Windows, gõ python --version (không có số 3). Con số phiên bản trên máy bạn có thể khác — miễn là 3.8 trở lên là học tốt. Nếu terminal báo "command not found", hãy xem lại bước cài đặt phía trên.

Chạy chương trình đầu tiên

Có hai cách chạy code Python: gõ trực tiếp trong REPL, hoặc viết vào file .py rồi chạy cả file. Ta thử lần lượt cả hai.

Cách 1 — REPL: gõ là chạy ngay

Gõ python3 vào terminal rồi nhấn Enter (Windows: gõ python). Dấu nhắc >>> hiện ra — đó là REPL, nơi bạn gõ lệnh nào nhận kết quả ngay lệnh đó.

REPL — gõ từng lệnh 
python3
Python 3.12.4
Type "help", "copyright", "credits" or "license" for more information.
>>> print("Xin chào")
Xin chào
>>> exit()
// GHI NHỚ

>>> là dấu nhắc do Python tự hiện — bạn không gõ nó. Thoát REPL bằng exit(), hoặc nhấn Ctrl+D (macOS/Linux) / Ctrl+Z rồi Enter (Windows).

Cách 2 — Viết file .py bằng VS Code

REPL hợp để thử nhanh, còn code thật nằm trong file .py. Hãy tải VS Code (miễn phí) rồi tạo file hello.py với nội dung:

hello.py 
print("Xin chào, Python!")

Lưu file, mở terminal ngay tại thư mục chứa file (VS Code: menu Terminal → New Terminal) rồi gõ:

terminal 
python3 hello.py
▸ KẾT QUẢ 
Xin chào, Python!

Để hiểu tận gốc, hãy giải phẫu lệnh vừa gõ thành từng bộ phận:
