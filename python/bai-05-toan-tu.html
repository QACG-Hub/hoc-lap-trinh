Toán tử số học

Toán tử (operator) là ký hiệu ra lệnh cho Python thực hiện một phép tính; biểu thức (expression) là sự kết hợp các giá trị và toán tử để tạo ra một kết quả mới, ví dụ 7 + 3. Bảy toán tử số học bạn sẽ dùng hằng ngày:

so-hoc.py 
print(7 + 3)     # cộng
print(7 - 3)     # trừ
print(7 * 3)     # nhân
print(7 / 2)     # chia thường → luôn ra số thực
print(7 // 2)    # chia lấy phần nguyên
print(7 % 2)     # chia lấy dư
print(2 ** 3)    # luỹ thừa (2 mũ 3)

Toán tử so sánh

Toán tử so sánh đặt hai giá trị lên "bàn cân" và trả lời một câu duy nhất: đúng hay sai? Kết quả trả về thuộc kiểu bool — chỉ có hai giá trị True hoặc False.

so-sanh.py 
print(5 == 5)    # bằng
print(5 != 5)    # khác
print(7 > 3)     # lớn hơn
print(7 < 3)     # nhỏ hơn
print(7 >= 7)    # lớn hơn hoặc bằng
print(3 <= 5)    # nhỏ hơn hoặc bằng

Toán tử logic

Một điều kiện thường chưa đủ — bạn cần nói "tuổi từ 13 đến 19", tức là hai điều kiện đúng cùng lúc. Ba toán tử logic giúp bạn kết hợp các điều kiện: and (và), or (hoặc), not (phủ định). Chúng chỉ làm việc với giá trị True/False.

logic.py 
tuoi = 15
print(tuoi >= 13 and tuoi <= 19)   # cả hai vế đều đúng?
print(tuoi < 13 or tuoi > 19)      # có ít nhất một vế đúng?
print(not (tuoi == 15))            # đảo ngược True/False

Đọc điều kiện như tiếng Việt cho dễ: tuoi >= 13 and tuoi <= 19 đọc là "tuổi lớn hơn hoặc bằng 13 và nhỏ hơn hoặc bằng 19". Viết and, or, not bằng chữ thường — viết hoa AND là lỗi ngay!

TỔNG KẾT BÀI 05

  • Toán tử số học: + - * / // % **; 7 / 2 ra 3.5, 7 // 2 ra 3, 7 % 2 ra 1, 2 ** 3 ra 8.
  • Thứ tự ưu tiên: ** trước, rồi * / // %, cuối cùng + -; ngoặc đơn luôn được tính trước.
  • Toán tử so sánh == != > < >= <= trả về True/False; = là gán còn == là so sánh.
  • Toán tử logic: and (cả hai đúng), or (một trong hai đúng), not (đảo ngược).
  • tuoi >= 13 and tuoi <= 19 là mẫu điều kiện kết hợp kinh điển — sắp dùng ngay ở bài if.
