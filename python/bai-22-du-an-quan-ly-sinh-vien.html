Đề bài & thiết kế dữ liệu

Đề bài: viết chương trình quản lý sinh viên cho một lớp học nhỏ. Yêu cầu tối thiểu: thêm sinh viên, xem danh sách, tìm theo tên, xóa theo tên, và có menu để chọn.

Trước khi gõ dòng code nào, dân chuyên nghiệp luôn thiết kế dữ liệu trước. Ở đây chỉ cần hai tầng: mỗi sinh viên là một dict {"ten": ..., "diem": ...}, còn cả lớp là một list các dict đó. Một list ôm nhiều dict — gọn gàng, dễ thêm, dễ duyệt!

du-lieu.py 
ds = [
    {"ten": "Nam", "diem": 8.5},
    {"ten": "Lan", "diem": 9.0},
]
print(ds[0])            # xem cả dict của sinh viên đầu
print(ds[0]["ten"])     # chỉ lấy tên
print(ds[0]["diem"])    # chỉ lấy điểm

Thêm & xem sinh viên

Mỗi chức năng gói gọn trong một hàm — code rõ ràng, muốn sửa ở đâu chỉ cần sửa một chỗ. Hàm them_sinh_vien(ds, ten, diem) chỉ làm đúng một việc: đóng gói thông tin thành dict rồi ds.append(...) vào cuối list. Hàm xem_danh_sach(ds) thì duyệt for sv in ds và in từng người.

them-va-xem.py 
def them_sinh_vien(ds, ten, diem):
    ds.append({"ten": ten, "diem": diem})

def xem_danh_sach(ds):
    for sv in ds:
        print(sv["ten"], "-", sv["diem"])

ds = []
them_sinh_vien(ds, "Nam", 8.5)
them_sinh_vien(ds, "Lan", 9.0)
xem_danh_sach(ds)

Tìm & xóa

Tìm kiếm là bài toán "duyệt tới khi gặp thì dừng": hàm tim_sinh_vien(ds, ten) trả về luôn dict tìm được, còn không thấy thì trả về None — và bên gọi chỉ cần kiểm tra if ket_qua is not None. Nhớ bài 18 không? Đây chính là cách tránh lỗi gọn nhất!

tim-kiem.py 
def tim_sinh_vien(ds, ten):
    for sv in ds:
        if sv["ten"] == ten:
            return sv
    return None

ds = [{"ten": "Nam", "diem": 8.5}, {"ten": "Lan", "diem": 9.0}]
ket_qua = tim_sinh_vien(ds, "Lan")
if ket_qua is not None:
    print("Tìm thấy:", ket_qua["ten"], "-", ket_qua["diem"])
else:
    print("Không tìm thấy!")
print(tim_sinh_vien(ds, "Hoa"))
▸ KẾT QUẢ 
Tìm thấy: Lan - 9.0
None

Còn xóa? Chiêu hay nhất là không xóa trực tiếp mà dùng list comprehension (bài 21!) để tạo list mới, giữ lại những người có tên khác người cần xóa:

xoa.py 
ds = [{"ten": "Nam", "diem": 8.5}, {"ten": "Lan", "diem": 9.0}]

# giữ lại mọi sinh viên KHÁC "Nam"
ds = [sv for sv in ds if sv["ten"] != "Nam"]
print(ds)
▸ KẾT QUẢ 
[{'ten': 'Lan', 'diem': 9.0}]
// CẢNH BÁO

Đừng vừa duyệt for sv in ds vừa ds.remove(sv) trực tiếp! List co lại ngay giữa lúc duyệt khiến index lệch và bạn sẽ bỏ sót sinh viên — lỗi "ma" rất khó phát hiện. Cứ lọc ra list mới như ví dụ trên.

Hoàn thiện & mở rộng

Giờ chỉ còn thiếu "trái tim" của chương trình: vòng while True lặp menu mãi cho tới khi người dùng chọn 0 để thoát. Đây là cách mọi ứng dụng dòng lệnh vẫn làm:

quan-ly-sinh-vien.py 
ds = []
while True:
    print("1. Thêm | 2. Xem | 0. Thoát")
    chon = input("Chọn: ")

    if chon == "1":
        ten = input("Tên: ")
        ds.append({"ten": ten, "diem": float(input("Điểm: "))})
    elif chon == "2":
        for sv in ds:
            print(sv["ten"], "-", sv["diem"])
    elif chon == "0":
        print("Tạm biệt!")
        break
▸ KẾT QUẢ (một phiên chạy mẫu — chữ sau "Chọn:", "Tên:", "Điểm:" là người dùng gõ)

  • Kiểm tra menu con: chọn "2. Xem" khi danh sách trống thì in "Danh sách trống!" cho thân thiện.
