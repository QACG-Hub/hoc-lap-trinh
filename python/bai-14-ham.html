Hàm (function)

[ NHIỆM VỤ #14 ] Chương 4 — Hàm & module Mức độ: Chiến binh

Bạn đã viết được kha khá code — nhưng cứ copy-paste một đoạn logic đi khắp nơi thì sớm muộn cũng rối như dây tai nghe trong cặp. Hàm (function) là chiếc hộp thần kỳ giúp bạn đóng gói một đoạn code, đặt tên cho nó, rồi gọi ra dùng bao nhiêu lần cũng được. Mở khóa chương 4 thôi! ⚡

def — đóng gói code

Một hàm được tạo bằng từ khóa def, theo sau là tên hàm, cặp ngoặc đơn chứa tham số, dấu hai chấm và phần thân thụt lề. Định nghĩa xong, bạn gọi hàm bằng tên kèm cặp ngoặc — lúc đó code bên trong mới chạy.

chao-hoi.py 
def chao(ten):
    print("Xin chào,", ten)

chao("Nam")
chao("Linh")
▸ KẾT QUẢ 
Xin chào, Nam
Xin chào, Linh

Viết def chao(ten): một lần, nhưng gọi được chao("Nam"), chao("Linh")… bao nhiêu người bấy nhiêu lời chào. Giờ hãy giải phẫu đầy đủ một định nghĩa hàm:

Tham số mặc định & keyword

Tham số có thể được cho sẵn một giá trị mặc định. Ai không truyền gì thì hàm dùng giá trị đó; ai truyền thì hàm tôn trọng người ta. Cách gọi kèm tên tham số chao(ten="Nam") gọi là keyword argument — nhìn là biết ngay đang truyền cái gì, không sợ nhầm thứ tự.

chao-mac-dinh.py 
def chao(ten="bạn"):
    print("Xin chào,", ten)

chao()             # không truyền gì → dùng giá trị mặc định
chao("Linh")       # truyền theo vị trí
chao(ten="Nam")    # truyền theo tên (keyword)
▸ KẾT QUẢ 
Xin chào, bạn
Xin chào, Linh
Xin chào, Nam

chao(ten="Nam")
Thành phầnÝ nghĩaBắt buộc
chaotên hàm cần gọi✅
ten=tên tham số + dấu = — truyền theo tên, không theo vị trí✅ nếu muốn dùng kiểu keyword
"Nam"giá trị truyền cho tham số ten✅
// CẢNH BÁO

Tham số có giá trị mặc định phải đứng SAU các tham số thường. Viết def chao(ten="bạn", tuoi): là Python báo lỗi ngay: non-default argument follows default argument. Nhớ quy tắc: tham số có "phao cứu sinh" xếp cuối hàng!

return & trả nhiều giá trị

Hàm xử lý xong có thể gửi kết quả ra ngoài bằng từ khóa return. Khác với print() (chỉ hiện lên màn hình), giá trị return được trả về đúng chỗ gọi hàm để bạn tiếp tục tính toán, gán biến, lồng vào biểu thức…

tong.py 
def tong(a, b):
    return a + b

ket_qua = tong(3, 4)
print("Tổng:", ket_qua)
print(tong(10, 20))
▸ KẾT QUẢ 
Tổng: 7
30

a + bbiểu thức được tính rồi gửi về chỗ gọi hàm❌ (viết return trống thì trả về None)

Hàm còn có thể trả về nhiều giá trị cùng lúc — Python tự gói chúng thành một tuple (bạn đã học ở bài 10!), và bạn có thể "bung" ra thành nhiều biến. Dòng chữ trong cặp """…""" ngay đầu hàm là docstring — tài liệu mô tả hàm:

min-max.py 
def min_max(ds):
    """Trả về (nhỏ nhất, lớn nhất) của danh sách."""
    return min(ds), max(ds)

nho, lon = min_max([7, 2, 9, 5])
print("Nhỏ nhất:", nho)
print("Lớn nhất:", lon)
print(min_max([7, 2, 9, 5]))
▸ KẾT QUẢ 
Nhỏ nhất: 2
Lớn nhất: 9
(2, 9)
// GHI NHỚ

return min(ds), max(ds) trả về tuple (2, 9) — dấu ngoặc đơn là của tuple, không phải của hàm. Viết nho, lon = min_max(...) là cách "bung" tuple ra hai biến, gọn như mở hộp quà!

TỔNG KẾT BÀI 14

  • Hàm đóng gói code để tái sử dụng: def ten_ham(tham_so): rồi thân hàm thụt lề bên dưới.
  • Định nghĩa hàm chưa chạy — phải gọi ten_ham(...) thì code bên trong mới thực thi.
  • Tham số có thể có giá trị mặc định, nhưng phải đứng sau tham số thường; gọi kiểu ten_ham(tham_so="giá trị") là keyword argument.
  • return gửi giá trị (hoặc gói nhiều giá trị thành tuple) ra khỏi hàm; không có return thì hàm trả về None.
  • Docstring """…""" ngay đầu hàm là tài liệu mô tả — viết ngắn gọn, rõ ràng.
