class & __init__

Class (lớp) là bản thiết kế, còn object (đối tượng) là sản phẩm đúc ra từ bản thiết kế đó. Một bản thiết kế HocSinh có thể đúc ra hàng nghìn học sinh: Nam, Lan, Hùng… mỗi người là một object riêng.

Trong class có một phương thức đặc biệt tên là __init__ — nó tự chạy ngay khi object được tạo, dùng để gán dữ liệu ban đầu cho object. Xem thử:

hoc-sinh.py 
class HocSinh:
    def __init__(self, ten):
        self.ten = ten
        print("Đã tạo học sinh", ten)

    def chao(self):
        print("Chào, mình là", self.ten)

hs = HocSinh("Nam")
hs.chao()
▸ KẾT QUẢ

Không hề có dòng nào gọi __init__, nhưng nó vẫn chạy — vì dòng hs = HocSinh("Nam") tạo object và Python tự động gọi nó, truyền "Nam" vào tham số ten. Hãy giải phẫu dòng định nghĩa đó:

Thuộc tính & phương thức

Dữ liệu gắn vào object như self.ten, self.diem gọi là thuộc tính (attribute). Còn phương thức (method) là hàm định nghĩa bên trong class — nó luôn nhận self để đọc/ghi dữ liệu của object. Object vì thế vừa biết nhớ, vừa biết hành động.

hoc-luc.py 
class HocSinh:
    def __init__(self, ten, diem):
        self.ten = ten
        self.diem = diem

    def hoc_luc(self):
        if self.diem >= 8:
            return "Giỏi"
        return "Cần cố gắng"

a = HocSinh("Nam", 8.5)
b = HocSinh("Lan", 6.0)
print(a.ten, "-", a.hoc_luc())
print(b.ten, "-", b.hoc_luc())
▸ KẾT QUẢ 
Nam - Giỏi
Lan - Cần cố gắng

Cùng một phương thức hoc_luc(), nhưng gọi trên a thì self là a (điểm 8.5 → Giỏi), gọi trên b thì self là b (điểm 6.0 → Cần cố gắng). Giải phẫu lời gọi:

Mỗi object có bộ thuộc tính riêng. Đúc hai chú mèo rồi đổi tên một chú — chú kia tuyệt nhiên không biết gì:

hai-chu-meo.py 
class Meo:
    def __init__(self, ten):
        self.ten = ten

m1 = Meo("Miu")
m2 = Meo("Mun")
m1.ten = "Vàng"          # đổi tên mèo thứ nhất
print(m1.ten, m2.ten)    # mèo thứ hai giữ nguyên tên
▸ KẾT QUẢ 
Vàng Mun
// GHI NHỚ

Class chỉ là bản thiết kế — dữ liệu thật nằm trong từng object. m1.ten và m2.ten là hai ngăn kéo khác nhau, sửa ngăn này không đụng ngăn kia.

// CẢNH BÁO

Quên self là lỗi kinh điển của người mới học OOP. Viết def speak(): (thiếu self) rồi gọi m.speak() sẽ báo TypeError — vì Python tự truyền object vào tham số đầu tiên, mà phương thức của bạn chẳng có tham số nào để nhận!

TỔNG KẾT BÀI 19

  • class là bản thiết kế; TenLop(...) đúc ra object (instance).
  • __init__(self, ...) tự chạy khi tạo object — dùng để gán thuộc tính ban đầu.
  • self là chính object đang thao tác; luôn đứng đầu danh sách tham số của phương thức.
  • Thuộc tính self.diem lưu dữ liệu; phương thức def hoc_luc(self) xử lý dữ liệu đó.
  • Gọi bằng dấu chấm: a.hoc_luc(); mỗi object có bộ thuộc tính riêng và độc lập.
