Dictionary — từ điển

Dictionary (dict) lưu dữ liệu theo từng cặp key: value (khoá: giá trị), viết trong cặp ngoặc nhọn { } — ví dụ {"toan": 8, "van": 9}. Mỗi key là duy nhất, dùng để tra ra value tương ứng.

tu-dien.py 
diem = {"toan": 8, "van": 9, "anh": 7}
print(diem)          # in cả dict
print(diem["toan"])  # tra theo key
print(len(diem))     # số cặp key: value

diem["tin"] = 10     # thêm cặp mới
diem["van"] = 8      # sửa giá trị của key có sẵn
del diem["anh"]      # xóa theo key
print(diem)

Tra key không tồn tại — ví dụ diem["ly"] — sẽ báo lỗi KeyError: 'ly'. Dictionary không tự "đoán" giúp bạn đâu. Muốn tra an toàn, xem mục sau với get().

Duyệt & xử lý dict

Dictionary có bộ "đồ nghề" duyệt rất tiện: keys() lấy các khoá, values() lấy các giá trị, items() lấy từng cặp (key, value) — thường dùng nhất. Còn get() là chiêu tra cứu an toàn: key thiếu thì trả về None (hoặc giá trị mặc định bạn chọn) thay vì báo lỗi.

duyet-dict.py 
diem = {"toan": 8, "van": 9}

for mon in diem.keys():
    print("Môn:", mon)

for diem_so in diem.values():
    print("Điểm:", diem_so)

for mon, diem_so in diem.items():
    print(mon, "→", diem_so)

print(diem.get("ly"))       # key không tồn tại → None
print(diem.get("ly", 0))    # có giá trị mặc định → 0

TỔNG KẾT BÀI 11

  • Dict lưu cặp key: value trong ngoặc nhọn: {"toan": 8, "van": 9}.
  • Tra giá trị bằng diem["toan"]; key không tồn tại → KeyError.
  • Thêm/sửa: diem["tin"] = 10; xóa: del diem["anh"].
  • Duyệt: keys(), values(), items() (từng cặp key, value).
  • Tra an toàn bằng get(key) hoặc get(key, mặc_định).
